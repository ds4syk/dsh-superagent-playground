# 研究日志：Padé / Salikhov / Rhin–Viola 型整系数线性型（μ(π) ≤ 2 方向）

窗口：`research/pi-exponent-parallel/pade/`。目标：证明 μ(π) ≤ 2 或给出精确障碍。
工作方式：先建可计算的成本模型，再对每个具体族做精确计算，用计算结果否证/确认，最后定障碍。

---

## 第 0 轮：口径与工具（20:49–19:52）

- 建立目录 `report.md` / `notes/` / `scripts/` / `data/`。
- 环境无 mpmath/sympy（系统 python3.10 与 conda base 都没有），**自建** `scripts/mp.py`：
  Decimal + Machin 公式算 π（60–1500 位可调），`Fraction` 做精确有理数。
  验证：π 前 60 位正确。
- 文献核对（仅一般文献）：Mahler 1953 `μ(π) ≤ 42`；Hata 1993 `≤ 8.0161`；
  Salikhov 2008 `≤ 7.6063`（现行纪录）；Rhin–Viola 1996 的 `5.441243` 是 **ζ(2)** 的。
  `μ(π)=2` 是猜想。→ 目标命题是公开问题，本窗口的现实产出应是"精确障碍 + 可复现计算"。

## 第 1 轮：先做 arctan 的 Padé 族（最自然的候选）

- 构造：`Q arctan − P = O(x^{4n+3})`，Hankel 系统 `Σ q_j(−1)^{m−j}/(2(m−j)+1)=0`，
  用 Fraction 精确解。得 `E_n = Q(1)π/4 − P(1)`。
- **结果（n=1…40）**：`|E_n| ≍ 23.31^{−n}`，分母 `D_n ≍ 95^n`，清分母形式 **增长** `≈4.1^n`。
  → 该族直接失败。
- 关键中间判断（当时是错的，第 2 轮修正）：一度以为"约分后的分母只有 1.457^n"，
  于是得到"指数 1.12"的荒谬结论。查表 `scripts/pade_vs_cf.py` 发现
  `P(1)/Q(1)` 约分后分子分母已有 `10^{74}` 量级：**Padé 值是分母极大的有理数**，
  函数层面的好逼近 ≠ 有理数层面的好逼近。

## 第 2 轮：质量不变量的正确形式（转折点）

- 重新推导引理，得到**分母平方定律**：`ϱ_n = |F_n||β_n| = D_n²|ℓ_n||b_n|`。
  `μ ≤ 2 ⟺ ϱ_n ≤ 1`。所以瓶颈是 `D_n ≤ (|ℓ_n||b_n|)^{-1/2} = D*_n`。
- 用它重算三条路线，一切自洽（见 report §6.2 差距表）。
- 同时把"例外有理数"的处理定稿：**不需要双族假设**——对每个固定有理数只有有限多个 n 使
  `p/q = −α_n/β_n`（因 `−α_n/β_n → π`），而 n(q) → ∞，故大 q 自动避开；小 q 有限个逐例处理。
  这比"两族独立线性型"更干净，且完全严格（report §2.1）。
- 另证"下界路线循环性"：`|a+bπ| ≥ c|b|^{−κ}` ⇒ `μ ≤ 1+1/κ`；`κ=1` 与目标等价（report §2.3）。
  → 任务里"对 |L_n| 给下界"的路线被精确定位为循环。

## 第 3 轮：正权单积分族——把"失败"变成**定理**

- 取 `W_n=(x(1−x))^n`（n≡0 mod 4 使 log 2 项消失）、核 `1/(1+x²)`。
  `W=Q(1+x²)+v`（带余除法无分母），`∫W/(1+x²) = A + (v/4)π`，`v=(1+i)^n=(−4)^{n/4}∈ℤ`。
- **正性 ⇒ 无抵消**：`L_n ≥ (1/2)∫W = (1/2)B(n+1,n+1)`，故
  `|α+βπ| ≥ 2D_n·n!²/(2n+1)!`，**严格**（不依赖任何 |L| 下界引理）。
  加上 `lcm` 分母税 `e^{2n}`：(3.5) 给出 `≳(e²/4)^n → ∞`。**严格证伪整类正权一维构造。**
- 数值（n≤40）精确复核 `α+βπ=4DL_n`（误差 <1e−100），实测增长 0.2–0.27 log₁₀/n
  与 `log₁₀(e²/4)=0.2665` 一致。
- 教训：**`4 < e²`** 是这类构造的死因；"每自由度衰减 log2 vs 税 1"的判据（report §6.3）
  由此提炼，可直接回答"为什么一维优化到不了 2"。

## 第 4 轮：衰减常数的机制（Legendre 增益）

- 猜 `E_n/J_n`（`J_n=∫(t(1−t))^n/(1+t²)`）是干净的指数：算到 n=50，
  斜率精确收敛到 `log₁₀(3+2√2)`（小数点后 4 位）。故 `23.31 = 4(3+2√2) = 4(1+√2)²`。
- 解释：`4^{-n}` 是质量项，`(1+√2)^{−2n}` 是 Legendre/Bernstein 椭圆增益
  （奇点 `t=i`，`|i+√(i²−1)|=1+√2`，平方来自余项核是 Legendre 多项式平方）。
- 检验 `c_n=|E_n/J_n|(3+2√2)^n ≈ 0.13√n`，与 `J_n≍0.886n^{−1/2}4^{−n}` 相容，
  且乘积常数 0.245 与 §4.2 拟合截距 `10^{−0.61}` 一致 → 自洽。
- 试过把 Padé 多项式识别成 Legendre/Gauss–Legendre 求积（`legendre_id.py`,
  `gauss_legendre_id.py`）：**否定**了"[n/n] ↔ n 点 Gauss"的朴素对应（根不匹配；
  Gauss 求积值反而更准）。故 report 只陈述"Bernstein 椭圆增益"这一机制层结论，不声称闭式。

## 第 5 轮：连分数——理想质量族与它的唯一障碍

- Lambert 的 arctan 连分数收敛子是整数，但 `|q_kπ − 4p_k| → 1.0616 ≠ 0`（常数！），
  **不给小的 1,π 线性型**。这是个容易踩的坑，已写入 report §4.5a。
- π 自身的收敛子：质量 `q_k|q_kπ−p_k| < 1` 自动成立（Dirichlet），`D=1`。
  **唯一同时满足 C1、C2 的族。**
- 例外处理要用第 k+1 个形式 ⇒ `μ(π) ≤ 2 + limsup log a_{k+1}/log q_k`（经典归约，本文重推）。
- 算 π 的前 ~900 个部分商：`k≥50` 时该量 ≤ 0.014；最大 1.39 在 k=1（小 q，可粗估）。
  `log q_600/600 = 1.1518`，Khinchin 几何平均 2.728，最大部分商 20776。
  → 数值上"一切都像 μ=2"，但没有证明。
- 这一步把障碍**压缩成一个经典对象**：π 的部分商增长。

## 第 6 轮：二维路线（Rhin–Viola 的舞台）能不能救 π？

- Beukers 型 `∫∫(x(1−x)y(1−y))^n/(1−xy)^{n+1}`：先算错（Beta 下标 off-by-one，
  把 `x^{k+n}` 当 `x^k`），得到"多项式衰减"的怪结果；用 2D Gauss–Legendre 求积
  交叉验证后修正（误差 1e−8…1e−14）。
- 修正后：衰减底 `11.09`（Richardson 外推 `λ=−2.4056`）`> e²=7.389` ⇒ **二维确实赢过 lcm 税**。
- 但 `[证明]` 值必属 `ℚ+ℚζ(2)`（被加项是完全平方 ⇒ 部分分式只有二阶极点 ⇒ 只出 ζ(2)）。
  ⇒ 给的是 μ(π²)。
- `[证明]` `μ(π) ≤ 2μ(π²)`，代入 5.441243 得 10.88 > 7.6063。**二维路线的精确障碍。**
- 几何根源：`1/(1+x²)` 的极点在 `±i`、距区间 1、**不落角点**，取幂只产生 `2^{−m}` 税；
  角点核（`1−xy`）才产生指数增益，但它的值域是 ζ(2) 而非 π。

## 结论（发给主窗口的版本）

- **已证**：归约引理（含例外处理的干净证明）；质量-分母平方定律；下界路线的循环性；
  正权族的严格衰减上限 `|L|≥½B(n+1,n+1)` 与精确分母阈值 `D_n ≤ 4^{3n/8}=1.68^n`
  （实测 `6.2^n`，差 3.66^n ⇒ 该族必然失败）；
  二维角点核的值必属 `ℚ+ℚζ(2)`（⇒ 只能给 μ(π²)）；`μ(π)≤2μ(π²) ⇒ 10.88`。
- **已算**：arctan–Padé：质量 `16^{-n}`、分母 `95^n`、清分母形式 `4.1^n` 增长；
  衰减常数精确分解 `4(1+√2)²`（Legendre 增益）；
  正权族精确整数表 + 严格下界；π 前 900 部分商与条件指数；Beukers 底 11.09。
- **未证**：μ(π) ≤ 2（公开问题）；也没有给出任何新的无条件 μ(π) 上界。
- **精确障碍**：`ϱ_n = D_n²|ℓ_n||b_n| ≤ 1`。三条路线分别差 `24^n`（Padé 分母）、
  `3.7^n`（一维衰减上限 `2^{-N}` vs 税 `e^N`）、以及在连分数路线上退化为
  "π 的部分商增长不受控"。
- **正面清单**：需要 (i) 求值点为整数/分母≤4^n 的 arctan 型算术 Padé；或
  (ii) π 部分商的控制；或 (iii) 值为 `ℚ+ℚπ` 的二维角点核。三者在文献中都是空白。
