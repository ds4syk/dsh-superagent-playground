# KITTI odometry: layer-level constrained PnP with roll/pitch cone + depth

Generated by `experiments/real/kitti/run_kitti_layer.py` +
`experiments/real/make_real_layer_tables.py`.  **Layer benchmark**: the 3D-2D
correspondences are Velodyne points projected with the GT motion (the shipped
KITTI-odometry subset has no images), perturbed by 1 px noise, an optional
downward pixel bias and optional wrong matches.  No detector, no RANSAC, no
robust loss -- the point is to isolate what the constraint layer does.

Reading notes: `cert` is only defined on the constrained problems (the
unconstrained QCQP has no `Shor` flag in `raw.json`-style tables), it is the
one-sided `J - Shor <= 1e-6` flag (an *upper bound* on the sound rate) and
`cert 2-sided` is the necessary condition.  `Projection` solves a different
problem (project the unconstrained point onto the feasible set), so its value
is usually *not* the constrained optimum and its cert rate is correspondingly
low -- that is expected, not a solver failure.
