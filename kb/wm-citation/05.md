# 05 三条谱系的演化与横向对比

> **结论先行**：三条线并不是并列的三个“方向”，而是同一问题的三代答案：**RWM 提出“用生成模型学世界”**，**Dreamer 把“在想象中训练”做成可用的算法**，**JEPA 把“预测”从像素搬到表示空间**。2024 年之后，三者在“视频生成式世界模型 + 动作条件”上合流。

**如果只记三件事**

1. **Dreamer 的遗产是训练范式**：RSSM + 想象 rollout + actor-critic；Dreamer 4 仍是这一范式，只是把世界模型换成可扩展的 Transformer 并用离线数据。
2. **JEPA 的遗产是表示哲学**：不重建像素、在嵌入空间预测、用正则防坍缩；它直接催生了 DINO-WM、LeWM、VLA-JEPA、FLARE。
3. **RWM 的遗产是问题定义**：VAE + RNN 的架构已被取代，但“世界模型 = 可交互的未来预测器”这一框架仍是所有工作的共同语言。

## 1. Dreamer 系：从“在想象中训练”到“在规模化想象中训练”

```
PlaNet (2019)          RSSM + 在线规划
   └→ Dreamer (2020)   RSSM + 想象 rollout + actor-critic
        └→ DreamerV2 (2021)   离散潜变量 + KL 平衡
             └→ DreamerV3 (2023/2025)  固定超参跨域 + symlog/two-hot
                  └→ Dreamer 4 (2025)   shortcut forcing + 高效 Transformer + 纯离线数据
```

**近三年的承接方式**：
- **直接续作**：Dreamer 4（1）是唯一在主表中的 Dreamer 系新作；它把“想象训练”从“在线交互”推进到“纯离线数据”，并用 Minecraft 钻石任务作为长时程基准。
- **作为基线**：TD-MPC2（A2）、WorldVLA（30）、机器人 VLA 工作普遍把 DreamerV3 当对照；DreamerV3 的“固定超参跨域”仍是 MBRL 的默认强基线。
- **作为骨架**：WorldVLA（30）把世界模型与动作模型统一到自回归框架，其“预测未来观测以改进行为”的思想直接来自 Dreamer 的想象训练。

**判断**：纯 RSSM 架构的创新已基本停止；Dreamer 系的价值转移到“训练范式”与“离线想象”上，未来更可能与视频生成骨干结合（Dreamer 4 已开始）。

## 2. JEPA 系：从“表征预训练”到“世界模型骨架”

```
LeCun 2022 立场论文   “联合嵌入预测架构”概念
   └→ I-JEPA (2023)   图像掩码 + 嵌入空间预测
        └→ V-JEPA (2024)   视频特征预测
             └→ V-JEPA 2 (2025)   视频理解 + 零样本规划（机器人）
                  └→ V-JEPA 2.1 (2026)   稠密预测损失 + 深层自监督
```

**近三年的分叉**：
1. **表征路线**：V-JEPA 2.1（4）继续提升稠密特征；图像世界模型（7）推广预测任务；大概念模型（6）把“在表示空间预测”外溢到语言。
2. **世界模型路线**：LeWM（2）解决端到端训练的稳定性与效率；DINO-WM（3）用冻结 DINOv2 特征 + MPC 做零样本规划。
3. **机器人路线**：VLA-JEPA（5）用 JEPA 预训练 + 动作头微调；FLARE（40）把未来潜表示对齐进扩散策略；mimic-video（36）用视频模型 + 逆动力学解码动作。

**判断**：JEPA 的“不重建像素”已成为视频世界模型的默认表征选择之一（DINO-WM、V-JEPA 2.1、LeWM）；但纯 JEPA 仍缺显式物理量与长时一致性，正在与 3D/物理监督融合。

## 3. RWM 系：从“VAE+RNN”到“视频生成式世界模型”

```
World Models / Recurrent World Models (2018)   VAE + RNN + 控制器
   └→ PlaNet (2019) / Dreamer (2020)   RSSM（RWM 的潜空间化）
   └→ 视频生成式世界模型 (2024–2026)   Cosmos / GameNGen / Matrix-Game / RELIC
   └→ 驾驶/机器人世界模型 (2024–2026)  DriveDreamer / Vista / OccWorld / DreamDojo
```

**近三年的承接方式**：
- **概念源头**：Cosmos（8）、GameNGen（12）、WorldDreamer（25）、GameGen-X（27）等把“世界模型”作为论文的核心叙事，RWM 是被引最多的概念来源之一（World Models 2018 在 2023 年后仍有 1650 次施引）。
- **架构替代**：VAE+RNN 被视频 tokenizer + 扩散/自回归 Transformer 取代；RWM 的“潜空间 + 预测 + 控制”三段式仍被保留。
- **评测延续**：WorldSimBench（46）、How Far（44）延续了“世界模型应预测未来”的评测视角。

**判断**：RWM 作为“架构”已经退出历史舞台，作为“问题定义”仍然是整个领域的共同框架；它的高被引主要来自概念引用，而非方法复用。

## 4. 横向对比

| 维度 | Dreamer 系 | JEPA 系 | RWM 系（含视频生成式后继） |
|-|-|-|-|
| 核心表示 | RSSM 隐状态（离散/连续） | 嵌入向量（ViT/视频 ViT） | 像素/视频 token 或 VAE 潜变量 |
| 训练信号 | 奖励 + 重构 + KL | 嵌入预测 + 正则（无奖励） | 重构/去噪 + 动作条件 |
| 输出 | 动作（策略） | 表征 / 规划代价 | 未来帧/视频 |
| 控制方式 | 想象 rollout + actor-critic | MPC/CEM 或接动作头 | 动作条件生成 + 规划/策略 |
| 典型算力 | 单卡到数十卡 | 单卡到数百卡 | 数十卡到万卡 |
| 代表（编号） | Dreamer 4 (1)、TD-MPC2 (A2) | LeWM (2)、DINO-WM (3)、V-JEPA 2.1 (4) | Cosmos (8)、GameNGen (12)、DreamDojo (35) |
| 优势 | 样本效率、可解释的想象 | 表征通用、规划便宜 | 保真度高、可利用互联网视频 |
| 局限 | 难利用无奖励视频、视觉保真低 | 无显式物理、长时漂移 | 算力昂贵、物理一致性无保证 |

## 5. 合流点：2025–2026 的“世界-动作模型”

三条线在机器人侧汇聚成 **World-Action Model（WAM）**：
- **DreamZero（29）**：视频扩散骨干 + 联合预测未来状态与动作，14B 模型 7 Hz 实时控制。
- **Cosmos Policy（33）**：单阶段把视频模型微调成策略，同时输出未来帧、动作、值。
- **WorldVLA（30）**：动作与图像统一自回归，互相增强。
- **VLA-JEPA（5）/ FLARE（40）/ mimic-video（36）**：JEPA/视频潜空间 → 动作头/逆动力学。

**这意味着**：世界模型与策略的边界正在消失——“先学世界模型、再学策略”的两段式，正在变成“联合建模世界与动作”的一段式。这也是本知识库最重要的趋势判断。

## 6. 三条线各自最值得读的三篇

| 谱系 | 最值得读 | 理由 |
|-|-|-|
| Dreamer | Dreamer 4 (1)、TD-MPC2 (A2)、WorldVLA (30) | 范式、基线、与 VLA 的结合 |
| JEPA | LeWM (2)、DINO-WM (3)、VLA-JEPA (5) | 端到端稳定性、零样本规划、机器人落地 |
| RWM | Cosmos (8)、GameNGen (12)、RELIC (22) | 基础模型、实时引擎、长时记忆 |
