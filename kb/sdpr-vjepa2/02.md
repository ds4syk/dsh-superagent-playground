# 02 接口分析：SDPR 能不能当 V-JEPA 2 的输出层？

> **结论先行**：按“解码器替代”理解——**不能**；按“几何结构化输出头”理解——**有条件可以**。
> 差别不是程度问题，是问题类是否匹配。

## 如果只记三件事

1. SDPR 输出的是**低维几何变量**，不是像素；它没有生成能力。
2. 只要下游任务是齐次 QCQP（位姿/旋转同步/标定/配准/IK），SDPR 就能作为输出头，
   反向把全局最优解的梯度传回适配器/编码器。
3. 前提是 Shor 松弛 tight、适配器给出合法参数、latent 含足够信息；否则只是一个
   “接上去但不可认证”的优化层。

## 0. 口径

本页把“SDPR 作为 V-JEPA 2 的一个层”拆成三种可检验的解读；判定依据是 SDPR 的问题类
（`[SDPR, Eq. (P1)]`）与 V-JEPA 2 的输出类型（`[V-JEPA2, §2–3]`）。

## 1. 对用户理解的核对

| 说法 | 判定 | 精确表述 |
|---|---|---|
| “SDPR 本身就是一个桥接” | **基本正确** | 它是“优化参数 → 全局最优解”的可微层；前向解 SDP，反向复用 KKT/证书。 |
| “把前向和反向的输入输出做一个连接” | **需修正** | 不是任意张量通路；共享的是 KKT 系统与证书，不是同一组激活。 |
| “使后端网络的输出能回传到前端” | **基本正确** | 只要前端参数进入 $Q_\theta$，输出损失就能经 $J$ 回传；但“前端”必须是产生优化参数的部分。 |
| “V-JEPA 2 没有输出，所以可以接 SDPR” | **需区分** | V-JEPA 2 缺的是解码器；SDPR 不是解码器，只能接几何结构化输出。 |

## 2. 解读 A：替代缺失的像素/视频解码器

**判定：不可以。** 这是问题类错误：

- SDPR 输出 $x^\*\in\mathbb{R}^n$，由 $Q_\theta$ 与二次约束决定；没有从 latent 到高维像素的
  生成机制，也没有像素似然/重建目标。
- JEPA 的“无解码器”是设计选择：在表征空间预测，避免把容量花在不可预测的像素细节上
  `[V-JEPA2, §1]`。SDPR 不能改变这个设计，也不能凭空产生像素信息。
- 硬接的后果：得到一个低维几何解，而不是视频。

这是**能力边界**，不需要实验反例；由问题形式直接判定。

## 3. 解读 B：几何任务的结构化输出头（本报告支持的解读）

**判定：有条件可以。** 数据流：

```
16 帧 → V-JEPA 2 编码器（冻结） → 每节点特征 f_t
      → 适配器 g_φ → 测量 (R̂_ij, w_ij) → Q_θ
      → SDPR（Shor SDP + 证书）→ 全局旋转 R̂_t
      → 损失 L(R̂_t, R_t*) → 经 KKT/证书反传到 g_φ（以及解冻时的编码器）
```

这正是“后端输出回传到前端”的可用版本：SDPR 是**输出头**，把“几何一致性/全局最优”
作为归纳偏置注入 V-JEPA 2 的下游。

成立条件：

1. **问题类**：输出必须是齐次 QCQP 的全局最优解；适配器输出的是合法 $Q_\theta$，不是任意向量。
2. **tight**：Shor 松弛 rank-1；否则没有全局最优/可信梯度。常用冗余约束、先验、足够测量来收紧。
3. **信息**：latent 必须含构造问题参数所需的信息；SDPR 不能创造信息。
4. **代价**：每样本每步一个 SDP；大规模要稀疏/分块/ADMM/GPU SDP。
5. **规范固定**：旋转同步有全局规范自由度，需要先验/锚点（本实验用 $R_0=I$）。

## 4. 解读 C：塞进 JEPA predictor 内部做几何一致性层

**判定：有限可行，但不是“输出桥”。** 如果 predictor 预测的是几何状态（位姿/轨迹），
可以在预测头后加 SDPR 做投影/优化；但这要求 predictor 输出本身是 QCQP 参数，且会改变
JEPA 的预训练目标。它更像“带几何约束的 predictor”，不是 V-JEPA 2 的通用输出层。

## 5. 判定表

| 解读 | 输出类型 | 是否可行 | 关键条件 |
|---|---|---|---|
| A 解码器替代 | 像素/视频 | **否** | 问题类不匹配；无生成能力 |
| B 结构化输出头 | 位姿/旋转/标定等 | **有条件可以** | QCQP + tight + 合法参数 + 信息足够 |
| C predictor 内部约束 | 几何状态 | 有限 | 改变预训练目标；需任务定义 |

## 6. 常见误读

- “SDPR 可微，所以可以接在任何网络后面”：可微不等于问题类匹配；输出必须是 QCQP 解。
- “JEPA 没有 decoder，所以缺一个输出层”：JEPA 是故意不要 decoder；缺的是任务头，
  不是通用解码器。
- “SDPR 的证书能证明 V-JEPA 2 的输出正确”：证书只证明**给定问题参数下** $x^\*$ 是全局最优；
  不证明问题参数/测量是对的，也不证明 latent 含有所需信息。
