# Constrained-QPEPLayer 合成桌面 PnP 主表

> 由 `experiments/code/make_results.py` 从 `results/raw_main.json` 自动生成；**不要手改**。

设置：合成桌面 6-DoF PnP（N=14 个 3D-2D 对应，bearing 型代数代价），逐点噪声 σ=0.010 m、系统性外参偏差 0.080 m，GT 恰好接触桌面；每格 50 trials，`seed=trial` 使不同 p/噪声档共享同一批场景。

p 的构成（非穿透/正深度/FoV 对/倾角 = 总数）：p=8: 5/2/0/1，p=16: 9/4/1/1，p=32: 17/8/3/1，p=64: 33/12/9/1。

方法：Unconstrained QPEP（多起点 48 起点数值全局） / Soft penalty（二次惩罚 λ=1e3，14 起点；λ 扫描见 Pareto 图） / Post-hoc projection（无约束解 → 最近可行点 SLSQP） / ALM-QPEP（冻结活跃集 + 定理 2.1 装配 + 一致性检查）。

统计：穿透/位姿误差给 **median [IQR]**（无约束解约 2% 的 cheirality 镜像模式会把 mean 拉爆，mean±std 在 CSV/JSON 里完整保留）；可行=违反≤1e-6，certified=可行且 $J-\mathrm{Shor}\le10^{-6}$ 且 SDP tight。
