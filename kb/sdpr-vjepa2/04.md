# 04 边界、反例与下一步

> **结论先行**：SDPR 作为 V-JEPA 2 的结构化输出头在接口上成立，但它是“几何逆问题的
> 可认证读出”，不是通用解码器；真正的瓶颈通常在表征/适配器，而不是 SDPR 本身。

## 如果只记三件事

1. 不适用：像素/视频/语言/任意高维输出；不能写成齐次 QCQP 的问题；松弛不 tight 且收不紧。
2. 适用但需工程化：每样本每步一个 SDP；$N$ 大时用稀疏/分块/ADMM/GPU。
3. 研究价值：不是“再刷一点精度”，而是**可认证性**（证书/置信度/拒答）和**全局梯度**。

## 0. 口径

本页区分三类“不适用”：

- **问题类不适用**：输出不是 QCQP 解（如像素生成）。
- **保证不成立**：问题类对，但松弛不 tight / 条件不满足，此时没有全局最优/可信梯度。
- **工程不划算**：问题类对、保证成立，但 SDP 代价/时延不可接受。

## 1. 什么时候不该用

| 场景 | 原因 | 替代 |
|---|---|---|
| 像素/视频生成、任意高维回归 | SDPR 无生成能力 | decoder / diffusion / 直接回归头 |
| 输出不能写成齐次 QCQP | 问题类不匹配 | 通用可微层（如 cvxpylayers）或直接头 |
| Shor 松弛不 tight 且无法收紧 | 无全局/可信梯度 | 局部求解器 + 诚实标注；或改问题形式 |
| $N$ 很大、时延敏感 | 每步 SDP 昂贵 | 稀疏/分块/ADMM、GPU SDP、局部求解器 |
| latent 不含几何信息 | 适配器无法恢复 | 换表征 / 加几何预训练目标 |

## 2. 实验暴露的边界

- 在 8 节点/13 边的旋转同步上，SDPR、chordal、局部最小二乘在 $\sigma=0$–$20^\circ$ 下
  误差几乎相同；**全局最优性不是这个任务的瓶颈**。SDPR 的独特价值是证书/全局梯度，
  不是“更准”。
- 端到端穿 SDPR 没有超过两阶段（全量: 1.18° vs 1.06°；pilot: 9.3° vs 8.9°；lr 大时发散）。
  SDP 解的梯度对求解器容差/条件数敏感：$N=4$ 良态时匹配 $5\times10^{-6}$，$N=8$ 学习测量
  上偏差可达 O(1)，所以端到端只能用 $10^{-5}$ 级 lr。
- OOD（未见全景）上 SDPR 管线 15.3°，反而差于 direct 12.7°；相对测量退化到 10.3°。
  说明瓶颈在表征/适配器，SDPR 不能修复坏测量。
- 这是**求解器精度/条件数**问题，不是 SDPR 公式错误；要在训练里用好它，需要更准的对偶
  （内点法/CLARABEL）、更好的缩放/冗余约束，或只在小 $N$/低精度要求下用。
- 真正的瓶颈更可能在表征/适配器：oracle 0.081° 与学习测量 8.9° 的差距，主要来自测量头。

## 3. 反例与误读

- **“证书证明端到端正确”**：证书只证明“给定 $Q_\theta$，$x^\*$ 是全局最优”；不证明
  $Q_\theta$ 的测量正确，也不证明 latent 有信息。
- **“SDPR 可微，所以能接任意前端”**：可微性成立，但输出必须是 QCQP 解；否则接上也没有
  问题类意义。
- **“JEPA 没有输出”**：JEPA 有输出（latent），没有的是 decoder；这是设计选择。
- **“tight 是永久性质”**：corank=1 时 tight 对小扰动稳定，但训练/数据分布变化仍可能破坏；
  要监控 rank gap 与 $H$ 的 PSD margin。

## 4. 如果要把它做成一篇真正的论文

1. **真实任务**：真实视频的相机位姿/物体位姿/多机标定；与直接头、局部求解器、谱方法比
   精度、鲁棒性、时延。
2. **可认证性的下游价值**：把 rank gap / $H$ 的 PSD margin 当作置信度/拒答信号；测试 OOD、
   遮挡、噪声下的选择性预测。这是 SDPR 相对普通头的独特卖点。
3. **端到端训练的信号**：相对损失预训练 + 全局损失经 SDPR 微调的稳定性；监控训练中的
   tightness。
4. **规模化**：利用稀疏性/clique 分解/ADMM，把 $N$ 从 8 推到 100+；或 GPU SDP。
5. **与 JEPA 的结合方式**：(a) 结构化输出头；(b) predictor 的几何一致性约束；
   (c) 规划时把 latent 距离与几何可行性结合。三条路要分别定义问题类与评价指标。
