# SDPR GPU 并行：负结果与设计记录

> 最终实现与验证在 `src/gpu_sdpr/`、`repro/gpu_sdpr/`；本文只保留“为什么不是 ADMM”和调参记录，避免误导后来者重复踩坑。

## 1. 原始 ADMM 为什么没有采用

在 (P6) 的 Shor SDP 上实现过“精确等式投影 + PSD 投影”的原始 ADMM：

- 变量 `X, Z, U`，`X`-步用 `A Aᵀ` 的法方程精确满足等式约束，`Z`-步做 PSD 投影（eigh 截断负特征值）。
- 25 个约束矩阵的秩只有 **18**（9 个范数约束线性相关），最初直接解 25×25 法方程导致 `ν` 发散；改为贪心选 18 个独立约束后法方程条件数 ~19，才稳定。

结果（B=20，float64，3000–10000 次迭代）：

| ρ | primal residual | `x` 相对误差（对 SCS） | `H` 最小特征值 |
|---:|---:|---:|---:|
| 0.3 | 5.7e-5 | 2.0e-1 | -1.6e-5 |
| 1.0 | 6.5e-5 | 2.0e-1 | -5.5e-4 |
| 3.0 | 7.6e-5 | 3.7e-1 | -1.0e-3 |
| 10 | 7.9e-5 | 5.5e-1 | -1.7e-3 |

原因：最优 `X` 是 rank-1（PSD 锥边界），投影的 dead-zone 让 primal residual 停在 1e-4 量级，`H` 出现负特征值，证书不成立。增加迭代/调 ρ 都不能解决。

## 2. 对偶 log-det barrier 的关键实现点

采用对偶 barrier 后，以下三处是调试中真正影响收敛的：

1. **X-步的符号**：`X = Y - Aᵀν`，不是 `+`；`ν` 解 `Mν = A(Y) - b`。符号错时 x 误差 ~90%。
2. **Hessian 的 `H^{-1/2}`**：`B_i = Lᵀ A_i L`，其中 `L Lᵀ = H^{-1}`；用 `H^{1/2}` 会让 Newton 方向错，梯度爆炸。
3. **PD 线搜索余量**：只要求 `λ_min(H) > 0` 会在 μ 很小时因舍入出现负特征值；用 `λ_min > 1e-13·max(1, λ_max)`，配合 Armijo 条件。

## 3. 调参

- μ 从 1e-2 开始、按 0.1 衰减到 1e-8；μ=1e-9 阶段线搜索失败（H 条件数 ~1e9），所以精度上限是 gap=13μ。
- float64；float32 的 eigh 在 μ 小时证书会失真（未系统测试）。
- 批量 eigh 是主要开销；18×18 Newton 系统的 `einsum` 批量构建比 Python 循环快一个数量级。
- `H` 的 `eigvalsh` 在 μ=1e-8 时最小特征值 ~7.7e-10，float64 仍可分辨；再小就会与舍入混在一起。
