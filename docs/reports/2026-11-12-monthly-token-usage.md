## 0. 口径

- 数据源：`~/.dsh/sessions` 下全部 101 个 session 的原始日志（v4 jsonl + zstd），逐条 `assistant/message` 的 usage 汇总，覆盖交互会话、labs 工作区、superagent 工单与 orchestrator 主会话。
- 计费 token = 未缓存输入 + 缓存读取 + 缓存写入 + 输出，与 dsh-context `contextActivity` 投影同口径；按每步 `step/start` 时间归入本地日期（Asia/Shanghai）；继承种子会话的种子事件不计入。
- 花费：DeepSeek 官方 CNY 列表价（deepseek-flash：缓存命中 ¥0.04、未命中 ¥2、输出 ¥8 每百万 token），工作日峰值（北京时间 9:00–12:00、14:00–18:00）单价 ×2、其余半价；属估算，不是 DeepSeek 平台账单。
- 窗口：2026-10-14 00:00 ~ 2026-11-12 16:12（30 天）。DSH 第一份日志在 10-20 18:16，首笔用量在 10-21；其余 18 天没有 DSH 会话记录：10-14~10-20（10-20 晚间才装好 DSH，尚无计费请求）、10-22~10-24、10-26~10-30、11-06~11-08。

## 4. 子会话（subagent）计入情况

- 30 天窗口内有 **24 个子会话**（`subagent/descriptor`，含 2 层嵌套子会话），合计 **238,835,270 token（占 7.91%）**、估算 **¥17.12（占 12.4%）**；父会话/顶层会话为 2,781,687,154 token、¥121.15。
- 子会话与父会话在同一 workspace 目录下各自拥有独立的 `session.v4.jsonl.zstd`（不是嵌在父会话日志里），本方法遍历 `~/.dsh/sessions` 下全部日志，因此**自动计入**；父会话的 `tokenUsage` 投影与其自身日志逐 token 一致，子会话用量只记在子会话日志里；只统计父会话或顶层会话的方法会少算这部分。
- 交叉印证：ticket b8f91d28 的近一周报告里也带有 `depth: 1/2` 的子会话条目，两者口径一致。
- 未计入项：标题生成（`session/title-llm-request`）与 Web Search/Fetch 的独立 LLM 请求没有 `assistant/message` usage 记录，本统计不计入（搜索/抓取按次另计，标题生成量很小）；失败重试的 `assistant/attempt` 不产生计费 usage。
- 脚本输出的会话条目带 `kind`（`main` / `subagent`），并汇总 `byKind`，后续可一键复核。

## 5. 校验与局限

- 与 DSH 官方 `tokenUsage` 投影逐会话比对：**100/101 完全一致**；唯一差异是正在写入的本期会话（投影缓存比日志快照少约 9.4 万 token，属正常滞后）。
- 与 ticket b8f91d28 的“近一周”报告交叉验证：10-31、11-01、11-02、11-03 四天的计费 token **完全一致**（107,162,253 / 215,468,501 / 309,289,745 / 1,210,951,374），说明统计口径稳定；11-04 因本次按全天、上次只到 02:25 而不同。
- `contextActivity` 投影缓存只回填了部分日期（且 11-01 之后不完整），因此本报告直接读原始会话日志复算。
- 局限：只统计本机 DSH 会话，不含其他工具/其他机器；跨午夜步骤按 `step/start` 归日；10-22~10-24、10-26~10-30、11-06~11-08 无 DSH 会话记录，按 0 计；当前会话仍在增长，数字为快照；花费为列表价估算，实际以 DeepSeek 账单为准。

## 6. 复算方法

一次性生成 30 天窗口的 JSON 与一页图：

```bash
node automation/monthly-usage.mjs --days 30 --json usage-30d.json
python3 automation/monthly-usage-chart.py usage-30d.json docs/visuals/2026-11-12-monthly-token-cost.png
```

- `--end YYYY-MM-DD` 可固定窗口结束日；`--days N` 改窗口长度；脚本对未知模型按 deepseek-flash 价兜底。
- 价格表集中在 `automation/monthly-usage.mjs` 的 `MODEL_PRICES`；价目变化时只改这一处。
