# 02 相关研究：决策模型当世界模型、当动作来源

> **结论先行**：直接把 JEV 放进 agent 世界模型的论文已经出现（KIIS 2026，TextWorld 成功率 93.4%），但把它**当动作生成器、再蒸馏进小学习器**的工作仍然很少；最接近的是 REFLEX（选择性控制）、JEV-as-Q（RL 辅助信号）与 JevVLA（8 万参数动作评价头）。这正好留出了本报告两个预实验的位置。

**如果只记三件事**：

1. KIIS 2026 证明「冻结 JEV + 可枚举状态变量」可以做文本 agent 的世界模型，4 步预测 77.9%，但动作仍由 Qwen3-4B 产生，JEV 只做预测。
2. REFLEX 证明 JEV 可以当快速动作决策层，少 72.7% 强模型调用；Good Judgment 则给出反例：控制器让成本 +19%、成功率不变。
3. 动作生成 + 蒸馏这条线上，JevVLA 用 8 万参数 energy head 证明「JEV 式候选打分」可压得很小；但还没有工作把 JEV 的世界模型/动作选择蒸馏进一个小策略并做闭环成本核算。

## 1. 直接前作：KIIS 2026 把 JEV 当世界模型

忠北大学 Song & Lee 的 2 页会议稿（KIIS 2026 秋季，oral，编号 00027）做了最直接的事：**冻结 JEV，不训练，问它「执行这条命令后，六个状态变量各是什么」**，用答案拼出下一状态，再喂回去做多步预测。任务是完全可观测的 TextWorld 双房间：开箱取钥匙、开锁、取目标食物、进远房，最短 6 步。策略固定 Qwen3-4B，每步提出候选计划，规划器用世界模型想象终态并打分，只执行第一步[8][9]。

关键数字（作者稿件，论文声称）：

| Agent | 成功率 % | 无效动作 % | WM 成本/ episode |
|-|-|-|-|
| 仅策略 | 17.0 | 87.8 | – |
| + 失败记忆 | 79.5 | 35.0 | – |
| **JEV（冻结）** | **93.4** | 15.4 | 129 请求，$0.010 |
| Qwen3-4B 决策式零样本 | 83.0 | 48.6 | 49 GPU-s |
| Qwen3-4B 生成式零样本 | 59.0 | 36.3 | 115 GPU-s |
| Qwen3-4B + LoRA（决策式/生成式） | 92.7 / 92.7 | 13.2 | 42 / 73 GPU-s |
| Oracle 引擎真值 | 92.7 | 12.8 | – |

- 4 步 rollout 精确匹配：JEV 77.9%，微调 LLM 98.5%/96.8%，零样本生成式 6.2%，persistence 15.6%。
- 新结构（多侧房、诱饵钥匙、第二容器）上：JEV 85.5%，微调 LLM 71.5%/66.5%；JEV 的下降小 25.6/26.7 个百分点。
- JEV 的错误几乎全在「命令是否执行」这一二值判断（单步 7.0%）；该判断正确时状态错误为 0.0%。

作者自己列出的 caveat 很重要：单一任务结构、单一 LLM、单 seed、单一解析规则；评测世界只是换名字、结构相同（69.5% 的评测转移在训练集中出现过）；新结构只是 rollout，不是闭环；在 parsed 答案上生成式并不比决策式差，决策式的优势是**格式稳健性**；oracle 只是诊断参照，存在天花板效应[8][9]。

**它没有做的事**：JEV 只当世界模型，不产生动作；没有蒸馏到小学习器；没有测 k>4 的长时程误差；没有做「同一候选集下 JEV 选动作 vs 策略模型选动作」的闭环对照。

## 2. 把 JEV 当动作来源：三条证据线

### 2.1 REFLEX：选择性控制

REFLEX（arXiv 2609.26532）用 JEV 做快速 typed decision layer，置信度低或需要生成时才调用强 LLM。冻结 100 任务基准上成功率 95%，比 strong-only 少 **72.7%** 的强模型调用；但在 BFCL 与 τ-style 外部评测上，相对便宜的生成式级联优势有限；可靠性取决于动作集大小和授权边界附近的近有效替代项[13]。

**读法**：JEV 适合「动作集有限、需要快速判断、允许在不确定时升级」的控制层；它不是万能策略。

### 2.2 JEV-as-Q：RL 里的位置

arXiv 2610.11692 系统讨论了 JEV 能当 RL 系统中的哪些角色：除价值函数这一基数用途外均可；然后把 JEV 用作 **reference policy、exploration judge、replay rater**，在 9 个 MiniGrid 与 3 个 Atari 上用 JEV 辅助训练优于标准 RL learner，且 JEV 始终冻结[17]。

**读法**：JEV 的输出可以变成训练信号，但该工作是「辅助 RL 学习」，不是「把 JEV 蒸馏成小策略」。

### 2.3 Good Judgment, Bad Advice：负结果

在 Terminal-Bench 2.1 上固定 agent loop，只换控制器。JEV 把每次尝试成本抬高 **19%**，通过率不变（73.0% vs 73.0%）；比小 LLM 控制器便宜，但比安慰剂贵 22%。离线看，JEV 对「完成请求」的排序更好（AUROC 0.78 vs 0.62/0.60），但校准很差：它给出「已完成」的平均概率 0.50 时，实际 87% 已完成，于是让 agent 去复核本来正确的活[14]。

**读法**：排序有信息量 ≠ 干预有价值；动作选择必须用闭环成功率与成本一起度量。这是本报告实验设计的直接教训。

### 2.4 JevVLA：8 万参数的动作评价头

JevVLA（arXiv 2610.35010）不是用 JEV 本体，而是借「结构化概率决策」的接口：冻结 VLA 基座，学习约 8 万参数的可微标量 energy，用执行反馈/专家纠正/偏好训练；energy 用于离散候选比较、梯度用于连续动作修正。MetaWorld MT50、VIMA、LanguageTable、LIBERO Plus、CLIPort 上分别比匹配基座高 1.28/2.31/1.60/1.52/1.28 个百分点[18]。

**读法**：把「JEV 式候选打分」压成极小动作头是可行的；这是「蒸馏」方向的存在性证明，但它蒸的是 VLA 基座，不是 JEV。

## 3. 相邻文献：LLM 世界模型的瓶颈

- **RAP**（EMNLP 2023）：LLM 同时当世界模型与推理 agent，用 MCTS 规划；在 Blocksworld/数学上显著提升[23]。
- **Xie et al.**（COLING 2025）：分别微调 precondition 与 effect 预测器，用合成数据扩增，并做人被试研究[24]。
- **Wang et al.**（ACL 2024）：ByteSized32-State-Prediction 基准，首次系统量化 LLM 当文本世界模拟器的状态转移；GPT-4 仍然不可靠[25]。

三篇的共同结论：**LLM 世界模型的瓶颈是状态转移的精确性与输出格式**，而不是「知不知道世界常识」。这解释了 KIIS 为什么强调 JEV 的优势是格式稳健性（不会生成无法解析的状态），而不是预测内容更准。

## 4. 经典世界模型：JEV 不在这个坐标系里

- Ha & Schmidhuber（2018）：VAE + MDN-RNN + 控制器，在梦里学策略[26]。
- DreamerV3：RSSM 隐状态 + imagination，单一配置 150+ 任务，Minecraft 从零挖钻石[27]。
- TD-MPC2：decoder-free 隐世界模型 + 局部轨迹优化，104 个在线 RL 任务，317M 参数跨 80 任务[28]。
- IRIS：离散 token 世界模型 + 想象训练[29]。
- DIAMOND：扩散世界模型，强调视觉细节[30]。
- Genie：从无标注视频学生成式交互环境，11B[31]。
- LeWAM（2026-10）：JEPA 式联合嵌入 + 动作 flow matching，接触密集任务 28.6%→89.7%，长时程 10.9%→46.2%，规划快 32.3×[20]。
- WorldVLA / V-JEPA 2：动作世界模型与视频世界模型的代表[38][39]。

这些模型都**生成或预测高维观测**，而 JEV 只在预设选项上给概率。JEV 不是「更便宜的 Dreamer」，它是「离散、可枚举、文本状态」这一窄轨道上的世界模型。

## 5. 动作生成与蒸馏的坐标

- **Decision Transformer**：把 RL 变成 return-conditioned 序列建模，直接生成动作[32]。
- **DAgger**：用专家在 learner 访问到的状态上打标，做数据集聚合；这是「强动作选择器教小策略」的标准理论工具，也是本报告 Exp2 的方法论来源[33]。
- **DreamGen**：视频世界模型生成 neural trajectories，再用 IDM/ latent action 恢复伪动作；单环境单任务遥操作数据让人形机器人学会 22 种新行为[34]。
- **UniSim**：从视频学可交互真实世界模拟器，训练具身/自动驾驶策略[35]。
- **OpenVLA / π0**：VLA 的离散/flow-matching 动作头[36][37]。
- **WorldVLA**：自回归 action world model，指出动作序列误差传播问题[38]。
- **V-JEPA 2**：动作无关视频 JEPA，加少量机器人轨迹对齐后零样本规划[39]。

**一句话**：文献支持「JEV 可以做离散文本状态的世界模型/决策层」，但还没有人回答「把它产出的动作蒸馏进小学习器是否划算」。两个预实验就是冲着这个空白去的。
