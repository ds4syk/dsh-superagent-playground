# UTIAS In-The-Dark: stereo landmarks + frustum / depth constraints

Generated by `experiments/real/utias/run_utias_layer.py` +
`experiments/real/make_real_layer_tables.py`.

**Only `run_000000` is usable**: it is the only run whose archive ships
`transforms_temporal.txt` (per-frame camera pose).  Runs 2/12 ship only
`transforms_spatial.txt`, which is a *static* camera<->vehicle transform
(~1 cm / 0.1 deg wobble), not a trajectory.  3D landmarks are real: ORB
left-right matches triangulated with f = 387.777 px and baseline = 0.239965 m;
the 2D observation in frame k+lag is the GT projection of the landmark (same
GT-projection layer as KITTI; real L->L ORB matching was measured first and
rejected, ~9 px median residual on the dark images).

## Data actually used

- run `run_000000`, 38 frame pairs x 3 settings, lags [15, 30], stride 60, n=80 landmarks/pair, FoV enforced on 20 border-near landmarks, depth on all 80
