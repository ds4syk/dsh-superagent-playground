## Limitations

1. Both measured runs are **daylight** (left-image mean intensity median 133 / 131, sky visible, official metadata lists run_000002 as morning/sunny), so this validates the format, calibration and GT protocol on real In-The-Dark archives, **not** night-time robustness.
2. The front-end is the hand-written SIFT+SGBM stereo front-end; the SDPR VGG/UNet front-end is not exercised here.
3. GT itself is the official registration output (spatial matches from place recognition + ICP); its per-pair noise is ~0.3-1.4 px equivalent, so the 0.01-0.02 m errors should be read as 'at the GT noise floor', not as absolute accuracy.
4. Only 15 consecutive pairs per configuration (single deterministic instance each); no injected outliers, no trials.
