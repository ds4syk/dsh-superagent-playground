# Anisotropic-weight $W_i$ ablation (3D-3D robust registration, GM/GNC)

Numbers are generated by `run_anisotropic.py` (fixed seeds, 25 trials/cell, N=100, p in [0.0, 0.3, 0.5, 0.7]). Raw per-trial records: `anisotropic_raw.jsonl`.

## 1. What is being solved (and what is not)

The correct robust objective with per-observation SPD weights $W_i$ is

$$\Phi(R,t)=\sum_i \rho(e_i),\qquad e_i=r_i^\top W_i r_i,\qquad r_i=R x_i+t-y_i,\qquad \rho(e)=\frac{c^2 e}{c^2+e},\ c=0.05.$$

At fixed GM weights $u_i=\rho'(e_i)$ the inner problem is $\min_{R,t}\sum_i u_i\,r_i^\top W_i r_i$. This is a **nonlinear** least-squares problem in the 6-DoF pose: the weights sit inside the residual, so it does **not** reduce to a scalar weighted Kabsch. `common.kabsch` solves $\sum_i u_i\|r_i\|^2$, which coincides with the correct objective only when all $W_i$ are scalar multiples of $I$.

This script solves the inner problem by 6-DoF Gauss-Newton on the Cholesky-whitened residuals $\sqrt{u_i}\,L_i^\top(R x_i+t-y_i)$ ($W_i=L_iL_i^\top$), re-anchoring the rotation chart every iteration. `scipy.optimize.least_squares` is run on the same problem as an independent check. Rows labelled **APPROX-sK** replace the inner solve by scalar weighted Kabsch; they are an explicitly labelled approximation, not a solution of the anisotropic objective.

Weight families: `identity` $W_i=I$; `diag` $W_i=\mathrm{diag}(d_1,d_2,d_3)$, $d_k\sim U(0.5,2)$; `full` $W_i=(A_iA_i^\top+0.05I)/\det(\cdot)^{1/3}$, $A_i\sim\mathcal N(0,I)$ (random Wishart, $\det W_i=1$). Weights are drawn from a seed stream independent of the data; the same instances are reused across the three weight families (paired comparison).

Ratio $J_{\mathrm{sK}}/J_{\mathrm{GN}}=1$ would mean the scalar inner is exact; $>1$ quantifies its error on the correct weighted objective.

## 6. Takeaways

* The scalar-Kabsch inner is exact for $W_i=I$ (median objective ratio 1.000000) but not for anisotropic weights: median ratio 1.0022-1.0068 (diag) and 1.0351-1.0884 (full). Scalar Kabsch therefore does not solve $\sum_i r_i^\top W_i r_i$ for anisotropic $W_i$.
* GNC-W reaches the lower (or equal) robust objective $\Phi$ than the scalar-Kabsch surrogate in 12/12 weight/p cells, confirming that the nonlinear inner solve minimises the weighted objective. A lower $\Phi$ need not mean a lower pose error when $W_i$ is misspecified relative to the actual noise.
* Diag vs $W=I$ (GNC-W, paired instances): median rotation change +0.007 to +0.020 deg across p, anisotropic solution better on 32-36% of paired trials, i.e. a small accuracy **loss**; the anisotropic weights do not improve accuracy here. The synthetic noise is isotropic, so anisotropic $W_i$ is a misspecified model; the experiment tests solver correctness, not a claim that anisotropy helps this data.
* Full vs $W=I$ (GNC-W, paired instances): median rotation change +0.055 to +0.124 deg across p, anisotropic solution better on 8-32% of paired trials, i.e. a small accuracy **loss**; the anisotropic weights do not improve accuracy here. The synthetic noise is isotropic, so anisotropic $W_i$ is a misspecified model; the experiment tests solver correctness, not a claim that anisotropy helps this data.
* GNC-W success across all (weight, p) cells is 92-100%; differences between weight families are in the sub-degree error regime, well inside the 5 deg / 0.1 success threshold.
* The correct anisotropic inner solve costs 5.2-23.0x the scalar-Kabsch approximation per GNC call (p50) and is still 47.5 ms at worst, which is the price of actually minimising the weighted objective.

## 7. Reading and limitations

* The nonlinear inner solve is only needed when some $W_i$ is genuinely anisotropic. When $W_i=w_i I$, scalar weighted Kabsch is exact and roughly an order of magnitude cheaper; production code should dispatch on that case. The runtime above is the straightforward GN implementation (no relative-cost stopping or LM damping), so treat the overhead as the unoptimised end of the range.
* The synthetic noise in `common.make_instance` is isotropic, so $W_i=I$ is the statistically correct weighting and any anisotropic $W_i$ is misspecified. The accuracy loss for diag/full in Section 4 is therefore expected and is not a solver defect: the solver is verified by the $W_i=I$ agreement with Kabsch, the scipy agreement, and the lower $\Phi$ versus the scalar surrogate. Whether anisotropic weights *help* when they match the true noise covariance is a separate matched-covariance study, not run here.
