# 05 合规路径与行动清单

> **结论先行**：先选路径，再花钱。对大多数课题组，最稳的顺序是：**境内合规模型/云服务 → 学校统一采购/集中账号 → 横向合作企业采购 → 学校对公境外采购 → 个人垫付**。个人垫付不是常规方案；如果已经发生，先停手、问财务、保留证据，不要去找“技术服务费”发票。

**如果只记三件事**：

1. **先确认科目和票据口径**，再决定买什么；不要“先买再找科目”。
2. **能用境内发票解决的，不要用境外订阅**；能用学校统一采购的，不要让个人垫付。
3. **数据合规是独立关卡**：涉密/个人信息/重要数据，财务同意也不能用境外 AI。

## 1. 决策树（按经费类型）

| 经费类型 | 第一步 | 有对应科目/合同 | 没有对应科目/合同 |
|---|---|---|---|
| **纵向财政经费** | 查预算科目：业务费—信息传播/其他相关支出，或学校自设的“数据服务费/云服务费” | 能取得境内发票 → 按真实品名报销；不能 → 学校对公境外采购，或换境内替代 | 先调剂/补预算，不要先买后报 |
| **横向课题** | 查合同：有没有“数据服务/云服务/软件使用费”约定 | 有约定 → 按合同 + 发票 + 验收报销 | 补合同/变更，或走学校“其他支出”；不要事后补“技术服务合同”套票 |
| **校级/包干经费** | 查学校细则：是否允许“数据服务费/软件服务费” | 允许 → 按真实品名报销 | 境内替代/学校统一采购；不要用个人消费冲抵 |

> 共同前提：不管走哪条，都要有真实业务、匹配票据、项目相关性、数据合规。任何一条不成立，后面的步骤都不用谈。

## 2. 五条路径排序

| 排序 | 路径 | 怎么做 | 优点 | 限制 |
|---|---|---|---|---|
| **A（推荐）** | 境内模型/云服务 | 阿里云百炼、火山方舟、腾讯云、华为云、百度千帆、DeepSeek 官方 API 等，签合同、开增值税发票（一般纳税人 6%） | 有发票、可对公、数据境内、科目好落 | 模型能力/生态与 OpenAI/Claude 有差异；需确认学校采购/科目 |
| **B（推荐）** | 学校统一采购/集中账号 | 图书馆/信息中心/科研院统一采购 AI 工具或模型服务，给项目分配账号/额度 | 一次采购、统一开票、统一数据评估；个人不报销 | 需要学校层面立项；周期长；不一定覆盖所有模型 |
| **C（可选）** | 横向合作企业采购 | 合作企业作为项目参与方采购 AI 服务，计入项目成本；或企业与学校签真实技术服务合同 | 合同灵活、发票在境内 | 必须有真实服务/交付；不能是代充；关联交易要报备 |
| **D（门槛高）** | 学校对公境外采购 | 国际处/采购处/财务处审批 → 合同 → 付汇 → 代扣增值税/所得税 → 对外支付备案 → 数据评估 | 最“正”；可取得境外 invoice + 完税凭证 | OpenAI/Anthropic 对中国大陆主体支持有限；流程长；个人版不可行 |
| **E（不建议）** | 个人垫付 + 找票 | 个人信用卡付 → 拿 receipt/账单 → 学校报销 | 快 | 合同主体是个人；税务链条断；审计易认定个人消费；找“技术服务费”发票风险高 |

### 2.1 路径 A：境内模型/云服务

适合大多数“想用 AI 但不想折腾报销”的课题组。关键点：

- 选能开 **增值税专用发票/普通发票** 的境内主体；
- 合同/订单写清服务内容、周期、用量、价格；
- 发票品名与合同一致（“云服务费/数据服务费/信息技术服务费”等）；
- 保留用量明细/账单，证明与项目相关；
- 提前和财务确认科目（“业务费—数据服务费/其他相关支出”或学校自设科目）。

### 2.2 路径 B：学校统一采购

适合学院/课题组多人使用、金额较大、需要数据合规评估的场景。可以推动：

- 图书馆把 AI 工具纳入“电子资源/数据库”采购；
- 信息中心采购“科研计算服务/模型 API 网关”；
- 科研院设立“AI 科研计算服务”专项/共享额度；
- 学校与境内云厂商签框架协议，按项目结算。

这条路的最大好处是：**把“个人报销”变成“学校采购”**，票据、科目、数据评估一次性解决。

### 2.3 路径 C：横向合作企业采购

如果课题组有横向课题/企业合作，可以约定由企业采购 AI 服务并计入项目成本，或企业向学校提供真实的技术服务（部署/集成/运维）并开票。注意：

- 合同要写清服务内容、交付物、验收；
- 企业要有相应能力和人员；
- 关联交易要报备/回避；
- 不能是“企业代充 + 开技术服务费”的通道。

### 2.4 路径 D：学校对公境外采购

只建议有国际采购经验的单位尝试。步骤：

1. 确认供应商能签合同、收对公款项、出 invoice；
2. 学校采购/国际处审批（可能涉及单一来源/竞争性磋商）；
3. 财务确认外汇来源、付汇路径、税务扣缴；
4. 单笔 >5 万美元：办理服务贸易对外支付税务备案；
5. 数据出境评估/网络安全/保密审查；
6. 取得境外 invoice + 付款凭证 + 完税凭证，入账报销。

### 2.5 路径 E：个人垫付

如果学校书面同意个人垫付，至少要做到：

- 账号/订阅明确用于项目，保留使用记录；
- 境外 receipt/invoice + 信用卡账单 + 翻译件；
- 项目负责人签字、学院盖章；
- 财务确认税务处理（是否视为个人消费/福利）；
- 不要用“技术服务费”发票替代真实凭证。

## 3. 问财务的 6 个问题（可直接复制）

1. **这笔“境外 AI 订阅/境内模型服务”应该落在哪个预算科目？** 是业务费—信息传播/其他相关支出，还是学校有“数据服务费/云服务费”子目？
2. **需要什么凭证？** 境内发票的品名/税率/明细要求是什么？境外 Invoice/Receipt + 信用卡账单 + 翻译件是否可以作为报销凭证？是否需要合同、验收、使用记录？
3. **是否允许个人垫付？** 如果允许，账号归属、使用证明、税务处理有什么要求？如果不允许，学校能否对公支付？
4. **学校能否对公采购境外服务？** 需要国际处/采购处/财务处哪些审批？代扣增值税/所得税怎么处理？单笔超过 5 万美元是否要备案？
5. **数据合规找谁审？** 项目数据是否涉及个人信息/重要数据/涉密？使用境外 AI 是否需要保密办/网信办/科研院审批？
6. **有没有校内集中采购/共享额度？** 图书馆、信息中心、科研院是否已经买了 AI/模型服务，课题组能否申请账号/额度？

> 建议用邮件/OA 提问并保留书面答复。口头说“可以报”，审计时不算数。

## 4. 问其他部门的 4 个问题

| 部门 | 问题 |
|---|---|
| 科研院/学院 | 这个项目/课题的预算里有没有可用的“数据服务/云服务/其他支出”？需不需要调剂？ |
| 保密办/网信办 | 项目数据能不能出境？使用境外 AI 是否触发数据出境评估/安全审查？ |
| 采购/资产 | 这笔支出是否达到采购/合同/资产登记标准？软件订阅算不算无形资产？ |
| 网络中心 | 校园网访问境外 AI 是否符合学校网络安全管理规定？是否需要统一出口/代理？ |

## 5. 材料清单（按路径）

### 5.1 境内模型/云服务

- 合同/订单/服务协议；
- 增值税发票（抬头、税号、品名、金额）；
- 付款记录（对公转账/公务卡）；
- 用量账单/资源使用记录；
- 验收/成果关联说明（如论文致谢、项目报告）。

### 5.2 境外订阅（如学校允许）

- 境外 invoice/receipt；
- 信用卡账单/银行汇款回单；
- 中文翻译件（内容、日期、数量、金额）；
- 合同/订单（如有）；
- 项目负责人签字、学院盖章；
- 汇率说明；
- 完税凭证（如学校代扣）；
- 数据合规审批（如适用）。

### 5.3 横向合作

- 横向合同/任务书；
- 服务合同/技术合同；
- 发票；
- 交付物/验收报告；
- 关联交易报备（如适用）。

## 6. 预算建议：把“AI 费用”写进下一个项目

如果课题组经常用 AI，最省事的办法不是每次找票，而是**在下一个项目预算里提前列支**：

- 在“业务费”下设“数据服务费/云服务费/AI 计算服务费”；
- 写明用途：模型 API 调用、云 GPU、数据存储、模型评测；
- 保留政策依据：国自然/重点研发业务费的“其他相关支出”；2026 年社情民意建议的“人工智能与科研计算服务费”方向；
- 如果学校有包干制/校级经费，优先用弹性更大的经费。

注意：预算里列了，不等于自动能报；还要符合学校细则、采购流程、票据要求。但“预算里有”至少解决了第一道关。

## 7. 如果已经个人垫付了，怎么办

1. **先停**：不要再买、不要再找“技术服务费”发票；
2. **问财务**：说明业务实质（项目使用、非个人消费），问有没有合法路径；
3. **备材料**：境外 receipt/invoice、信用卡账单、翻译件、使用记录、项目关联说明；
4. **接受结果**：如果学校明确不能报，就按个人消费处理；不要为了几百/几千元去冒虚开风险；
5. **复盘**：下一次走境内模型/学校统一采购/横向合同，把预算和科目提前安排好。

## 8. 本页结论

- **路径选择比“找发票”重要**：A/B 两条路能解决 80% 的需求；C 适合有横向合作的团队；D 是少数单位的能力；E 是例外，不是常规。
- **先问财务，再花钱**：6 个问题问完，基本就能判断能不能报。
- **数据合规不能省**：财务同意只是第一关，涉密/个人信息/重要数据出境是独立红线。
- **预算前置**：下一个项目把“数据服务费/云服务费”写进去，比事后找票更稳。
