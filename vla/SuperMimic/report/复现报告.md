# SuperMimic 复现报告（2026-11）

> 本报告记录论文 *SuperMimic: Scaling Humanoid Whole-Body Control with One Differentiable World Model*（CoRL 2026，arXiv:2610.28480）的复现过程。结论以「本仓库跑出」的证据为准，论文数字统一标注为「论文声称」。

## 0. 摘要

在 `/mnt/storage1/syk/VLA/SuperMimic` 下克隆官方实现（`HybridRobotics/supermimic` + `HybridRobotics/mjlab_research`），用 `uv` 建 Python 3.13 环境，下载 LAFAN1 的 40 条 G1 动作（2.45 h）并转换为 mjlab npz；通过 Slurm 在单张 RTX 5090 上跑通 SuperMimic 的「可微分世界模型 + BPTT 策略」训练，并用同环境、同动作库的 rsl_rl PPO-Sim 做同预算对照。

**结论**：

- 官方实现单卡 1.5 h 训练出 Appendix-F 归一化回报 **0.859**（40 条 LAFAN1，最低 0.815，1 条失败），复现了论文 LAFAN1 受控实验的 **0.82**。
- 同预算 PPO-Sim 只有 **0.210**（38/40 失败）；SuperMimic 在约 0.3 h 的训练回报已超过 PPO-Sim 1.5 h 的最终值。
- 官方测试 **217 passed**；世界模型加权状态损失 3.03 → 0.0089，训练稳定。
- 未覆盖：BONES-SEED 全量、SONIC、>1000× GPU-hours、真机、多卡、下游接口。

## 1. 复现目标与范围

- **要复现什么**：可微分世界模型 + BPTT 策略训练的完整链路；与 model-free PPO-Sim 在同动作库、同预算下的对比；世界模型训练损失等机制性指标。
- **不覆盖什么**：BONES-SEED 全量 129,514 条动作（264 h）、SONIC 检查点、128 卡训练、真机 G1 部署、多卡扩展、下游速度接口。
- **判定标准**：
  1. 官方实现能在单卡上跑通训练；
  2. 训练回报上升，检查点在 40 条 LAFAN1 动作上有可解释的归一化回报；
  3. 同预算下 SuperMimic 与 PPO-Sim 的相对关系可量化；
  4. 世界模型训练损失可量化。

安装与运行注意：

- `uv sync --python 3.13` 在登录节点完成；训练/评测全部 `sbatch`，单卡、日志落数据盘。
- 该环境下 `mujoco` 包内同时存在 `libmujoco.so.3.16.0` 与 `libmujoco.so.4.0.1`，插件 `.so` 的 RUNPATH 指向构建机路径，直接 `import mujoco` 会报 `libmujoco.so.3.16.0: cannot open shared object file`。解决：运行前把 `site-packages/mujoco` 加入 `LD_LIBRARY_PATH`（脚本已内置）。
- 官方 `mjlab.scripts.csv_to_npz` 强制上传 W&B registry；本复现用等价的本地脚本 `repro/csv_to_npz_local.py`（内部调用 mjlab 的 `MotionLoader`），字段完全一致。
- 单卡训练用 W&B offline（`WANDB_MODE=offline`）；checkpoint 上传到 W&B 会因无 API key 警告，但本地 `world_model.pt / actor.pt / critic.pt` 正常保存。

## 3. 数据

- 来源：HuggingFace `lvhaidong/LAFAN1_Retargeting_Dataset` 的 G1 retarget（30 fps CSV，Unitree 广义坐标 `[root_pos(3), root_quat_xyzw(4), joint_pos(29)]`）。
- 规模：40 条动作，264,705 帧 @ 30 fps = **2.451 h**；50 Hz 后 441,140 帧（单条 102–273 s）。
- 转换：`repro/csv_to_npz_local.py` → `motions/lafan1_npz/*.npz`；PPO-Sim 另用 `mjlab.scripts.pack_motions` 打包为 `motions/lafan1_packed/`（mjlab 的 CLI 只接受已存在的路径，glob 会被 `Path.exists()` 判为不存在）。
- 与论文差异：论文主结果用 BONES-SEED（129,514 条，264 h）；LAFAN1 只用于论文 Figure 4 的受控对比，本复现复用同一受控设置。

## 4. 实验与结果

### 4.1 官方测试

`pytest tests -q`：**217 passed**（15.5 s，CPU，使用 `LD_LIBRARY_PATH` 修正）。

### 4.2 训练

| 实验 | 配置 | Slurm job | 结果 |
|-|-|-|-|
| smoke | 512 envs, 30 iters | 2736 | 全链路跑通 |
| SuperMimic | 4096 envs, proprio + history 10, 1.5 h | 2737 | 32,000 iters，训练 proxy 0.284 → 0.853 |
| PPO-Sim | 4096 envs, rsl_rl, 1.5 h | 2740 | 9,209 iters，训练 proxy −1.71 → 0.335 |

| 指标 | SuperMimic | PPO-Sim |
|-|-|-|
| 每迭代 env steps | 4,096 | 98,304（24 × 4096） |
| 总 env steps | 1.31 亿 | 9.05 亿（约 6.9×） |
| 墙钟 | 1 h 32 min | 1 h 35 min |
| 吞吐 | ~23.7k env-steps/s | ~159k env-steps/s |
| 训练 proxy 达到 0.82 | 约 0.55 h | 未达到 |
| 训练 proxy 最终 | **0.853** | **0.335** |

> proxy = 训练 episode 的 `mean_reward / (0.1 × mean_episode_length)`；训练 episode 在 500 步截断并使用 return-based reset 采样，**不是** Appendix-F 的整段归一化回报。跨方法比较时两者用同一 proxy。

曲线：`results/training_curves.png`。

### 4.3 检查点评测（Appendix-F 协议）

| 策略 | 均值 | 最低 | 失败数 |
|-|-|-|-|
| **SuperMimic** | **0.8588** | 0.8153 | **1 / 40** |
| PPO-Sim | 0.2099 | 0.0013 | **38 / 40** |

- SuperMimic 的 40 条动作全部在 0.815–0.921；唯一失败是 `jumps1_subject2`（在 11940/12222 步触发 anchor 终止，回报仍 0.825）。
- PPO-Sim 仅 `walk1_subject2`（0.704）与 `walk3_subject2`（0.745）完成整段，其余基本在起步阶段终止。
- 逐条分布：`results/eval_bars.png`；原始数据：`results/eval_supermimic.json`、`results/eval_ppo.json`。

与论文对照：

| 项 | 论文声称 | 本复现 |
|-|-|-|
| LAFAN1 40 条，单卡到 0.82 | 1.2 h（1×H100） | **0.859 @ 1.5 h（1×RTX 5090）** |
| PPO-Sim（1 GPU，18 h 预算） | 0.60，未达到 0.82 | 0.210 @ 1.5 h（预算约 1/12，不能直接比） |

| 通道 | 首个记录 | 末尾记录 |
|-|-|-|
| `Loss/state`（加权合成） | 3.0319 | **0.0089** |
| `Loss/root_pos` (MSE) | 0.0007 | 0.0000 |

## 5. 与论文的差距与归因

| 项 | 论文 | 本复现 | 影响 |
|-|-|-|-|
| 动作库 | BONES-SEED 129,514 条（264 h）；LAFAN1 40 条用于 Figure 4 | LAFAN1 40 条（2.45 h） | 只验证受控对比，不验证数据规模 scaling |
| 基线 | SONIC（128×L40，7 天）+ PPO-Sim（18 h） | 仅 PPO-Sim（1.5 h） | 不能复核 >1000× GPU-hours；PPO-Sim 远未训完 |
| GPU | H100 80 GB | RTX 5090 32 GB | 并行环境/批量受显存限制 |
| 训练时长 | 3 h / 320k 迭代；受控实验 1.2 h 到 0.82 | 1.5 h / 32k 迭代 | 回报已接近，迭代数少一个量级 |
| 观测 | Table A.1：proprio + 最近 10 帧 | 按论文取 proprio + history 10 | 与官方 runner 默认（rep_state + 1 帧）不同 |
| 评测域随机化 | 无 | 事件函数置为 no-op（保留 spec 供 SimContext 使用） | 与论文一致 |
| 真机 | Unitree G1，4 类动作 | 无 | 不覆盖 sim2real |
| 下游接口 | 速度编码器（RL vs 蒸馏） | 无 | 不复现 §4.5 |

## 6. 复现结论

1. **核心数值可复现**：官方实现 + LAFAN1 + 单卡 1.5 h 得到 0.859，复现论文 LAFAN1 受控实验的 0.82。
2. **效率方向一致**：同预算 PPO-Sim 只有 0.210（38/40 失败）；SuperMimic 在 0.3 h 的训练回报就超过 PPO-Sim 1.5 h 的最终值。
3. **不能声称**：本复现没有验证 BONES-SEED 全量、SONIC 对比、>1000× GPU-hours、真机迁移；PPO-Sim 的 18 h 曲线未跑。
4. **工程可复用**：数据转换、Slurm 脚本、离线 W&B、评测脚本都在 `vla/SuperMimic/repro/`，可直接扩到更多动作或更长预算。
