# 05 把 QPEP 做成可微优化层：方案、边界与三个问题的最终回答

> **结论先行**：可行，但要把"**前向枚举**"与"**反向微分**"拆开设计：前向用 **4 支近似（249 模板）产生候选 + full KKT 上的 LM 精化 + loss 比较**（实测 5 ms/次、0.01°–0.19°）；反向**只对精化后的 5×5 full KKT 做隐式微分**（与重解差分吻合 1e-9），**不要**对 3-of-4 系统微分。全局最优性：full 模式是"代数全局（有条件）"，近似+LM **没有保证**；QPEP 没有 SDPR 那样的对偶证书，所以可微层只能给出**损失 gap + KKT 残差 + SOSC/条件数诊断**，不能声称"certifiable"。

**如果只记三件事**：

1. **前向**：分支只负责"落到哪个驻点"，LM 负责"落到一个驻点"，loss 比较负责"选哪个驻点"；三者职责分明。
2. **反向**：$\mathrm dz/\mathrm d\theta=-M^{-1}\partial F/\partial\theta$，$z=(q,\lambda)$；$M$ 是 5×5，SOSC 下非奇异；实测对有限差分 $10^{-9}$。
3. **不要做的事**：对 3-of-4 微分（得到另一个映射的导数，实测差 0.12–25.7 倍）；把"近似模式"当全局解；把"代数全局"当"可验证全局"。

## 1. 架构：一个"三明治"层

```
θ (数据/权重)
  │
  ├─(1) 组装 W,Q：O(N)                        [无需求导，纯求和]
  │
  ├─(2) 四支 3-of-4 近似（249³ 消除）→ 至多 4×27 个候选
  │        （可选：full 596³ 枚举，若数值可用）
  │
  ├─(3) 每个候选 → full KKT (q,λ) 上的 GN/LM 精化 → 驻点集合 {z_i}
  │
  ├─(4) 选 loss 最小者 z*；记录 second-best、λ*、KKT 残差、cond(M)、
  │        ‖q‖−1、SOSC 最小特征值 → 诊断量
  │
  ▼
前向输出 q*, t(q*)
  │
  └─(5) 反向：M dz = −(∂F/∂θ) dθ，取 dq*/dθ
           （∂F/∂θ 可用解析式/自动微分/复步长，O(N)）
```

### 1.1 为什么前向要"分支 + LM"而不是"分支直接选"

03 页已证明：含噪时四支都不含真实最优（0/20），分支解只是 $O(\lambda/\sigma_{\min})$ 的近似。所以：

- **分支提供的是 basin**：它的解足够近，使 LM 收敛到正确的驻点（实测 PnP 0.01°–0.19°、0/30 失败）；
- **LM 提供的是 KKT 精度**：精化后 $F(z^*)\approx0$，这是反向隐式微分的前提；
- **loss 比较提供的是"哪个驻点"**：四支的 LM 终点若不同，取 loss 最小；若相同，合并。

### 1.2 为什么反向是 5×5 而不是 4×4

- $4\times4$ 的 3-of-4 系统：解的是 $\lambda=0$ 的投影问题，导数不是原问题的（03 页 §3）；
- $5\times5$ 的 full KKT：解的是原问题，$\lambda$ 是未知量而不是参数；SOSC 下非奇异。

### 1.3 伪代码

```python
def qpep_layer(theta):
    W, Q = assemble(theta)                    # O(N)
    cands = []
    for perm in PERMS4:                       # 4 支
        sols = solve_approx(W[perm], Q[perm]) # 249 模板，至多 27 个
        cands += [refine_full_kkt(s, W, Q) for s in sols]
    zs = dedup([z for z in cands if converged(z)])
    losses = [L(z) for z in zs]
    i = argmin(losses)
    diag = dict(gap=losses[second_best]-losses[i],
                kkt_res=norm(F(zs[i])),
                cond=cond(M(zs[i])),
                lam=zs[i].lam, sos_min=eigmin(H_restricted))
    return zs[i].q, t(zs[i].q), diag

def qpep_backward(z, theta, dL_dq):
    M = kkt_jacobian(z, theta)                # 5×5
    N = dF_dtheta(z, theta)                   # 5×p，O(N)
    dz = -solve(M, N) @ dL_dq                 # 或先解 M^T y = dL_dq
    return dz.q                               # 只回传 q（t 由 q 决定）
```

> 反向实现细节：与 SDPR 一样，不必显式构造 $M^{-1}$；先解 $M^\top y=\nabla_q\ell$（5×5，微秒级），再 $\nabla_\theta\ell=-y^\top\partial F/\partial\theta$。

## 2. 全局最优性：能保证到什么程度

| 路径 | 全局性 | 证书 | 代价 |
|-|-|-|-|
| full 枚举（596 模板） | **代数全局**：枚举全部 KKT 根 + 比较目标（前提：消元不漏根、数值稳定） | 无 | 70–90 ms；复现中数值失败 |
| 近似 + LM | **无**：LM 只到局部驻点；分支只是初值 | 无 | 5 ms |
| 近似 + LM + 多起点/K 次重启 | **经验全局**：用采样提高命中率，仍无证明 | 无（可报 gap） | 5 ms × K |
| QPEP + SDPR 混合 | 前向 QPEP 全局候选，后向若 SDP 松弛 tight 则用 SDPR 证书 | **有**（tight 时） | SDP 代价 |

要点：

1. **"full 模式可证全局"要加两个前提**：消元模板完整（不漏根、不引入伪根）且数值上能区分重根。论文给出了 full 的 40 解上界与模板，但没有对偶证书；**"证"的是代数枚举的完备性，不是凸证书**。
2. **近似模式不保证全局**：它甚至不保证"四支里有一支对"（含噪 20/20 都不含全局最优）。它能保证的是"给 LM 一个好初值"。
3. **可微层的"全局"要求更强**：不仅要前向全局，还要"参数小扰动下全局解不切换"。SDPR 用 tight + corank=1 处理；QPEP 只能**监控**（loss gap、second-best、$M$ 的条件数），切换发生时梯度不连续，必须**显式降级**（断开梯度/回退局部解/报诊断），不能假装可微。
4. **cost 与模型不一致的风险**：QPEP 的"全局"是对**代数代价**（如 PnP 的代数误差、点到面误差）的全局；如果下游要的是重投影 ML 代价，全局解不等于 ML 解。可微层必须明确它的前向目标是什么。

## 3. 与 SDPR 的对照：两条"可信梯度"路线

| 维度 | SDPR | 本方案的 QPEP 层 |
|-|-|-|
| 前向 | Shor SDP + rank-1 读出 | 249 模板四支 + full KKT LM + loss 比较 |
| 全局性 | tight ⇒ 全局 | full 枚举（有条件）；近似+LM 无保证 |
| 证书 | $H\succeq0$、corank=1（可独立检验） | 无；只有 gap/残差/条件数诊断 |
| 反向 | Thm.2：$M_r^\dagger$、唯一 Jacobian | 同构的 IFT：$M^{-1}$（5×5） |
| 多全局解/切换 | 有理论边界（Thm.2 条件） | 只能检测与降级 |
| 代价 | 每步 SDP（$n$ 大多项式） | 每步 249³（常数） |
| 适用 | 高维/多旋转/需要证书 | 低维、多测量、多模态几何问题 |

**结论**：QPEP 层的定位不是"替代 SDPR"，而是"**在 SDPR 的 SDP 太贵/不 tight 的低维问题上，提供一条 5 ms 级、梯度正确的路径**"；它放弃了证书，换取了固定常数代价与不依赖 tightness。

## 4. 风险与失败模式（必须在层里显式处理）

| 风险 | 症状 | 处理 |
|-|-|-|
| 249 模板病态/消元失败 | 候选缺失、loss 异常 | 检查 KKT 残差；失败则换 full 或局部求解器 |
| 分支 $J_k$ 奇异 | 分支 LM 不收敛（实测 2/32） | 跳过该支；不要对它求导 |
| full KKT $M$ 奇异（SOSC 失效/多解） | cond 爆、梯度巨大 | 断开梯度、标记退化、回退 |
| 全局极小切换 | loss gap→0、梯度跳变 | 监控 second-best；切换时置零/回退 |
| $\lambda$ 很小但非零 | 分支解接近最优、导数却不同 | 仍用 full KKT 求导（不要用分支） |
| 四元数符号 | $q$ 与 $-q$ 同解 | 固定符号（如 $q_0\ge0$）后再求导；注意切换面 |
| 代数代价 ≠ ML 代价 | 前向"全局"但下游不认 | 明确损失定义；必要时外层再精化 |

## 5. 三个问题的最终回答

### Q1：选三个方程会不会过约束？

- **4 行 + 范数 = 5 方程 4 未知 → 超定**，而且结构上不一致（真实最优的四行残差是 $\lambda q_i$，$\lambda\ne0$ 时都不为零）。
- **3 行 + 范数 = 4 方程 4 未知 → 方阵**，但它解的是 $\lambda=0$ 的投影问题；只在 $\lambda=0$（无噪/零残差）时与真实最优重合。
- 所以"选三个"不是"修好了过约束"，而是"**换了一个可解的问题**"；它的正确用途是初值。

### Q2：四组方程的解会不会落在两个方程上？该求哪个微分？

- **$\lambda=0$ 时**：四支的根完全重合（实测 4/4 实例、6 对根两两重合），此时"解同时在四个方程上"。
- **$\lambda\ne0$ 时**：一支都不含真实最优（实测 0/20）。
- **该对谁求微分**：**都不对**。四支在重合点的导数彼此差 0.6–26 倍；只有 full KKT 的导数与"重解差分"一致（1e-9）。分支只用于初值与筛选。

### Q3：这玩意能保证全局最优吗？

- **full 模式**：在"消元完整、数值可靠"的前提下，枚举全部驻点并比较目标 ⇒ **代数全局**；但**没有凸证书**，不能像 SDPR 那样独立验证；复现中 596 模板数值失败（未验证）。
- **近似模式**：**不保证**；它只是初值，最终由 LM 决定，LM 是局部的。
- **可微层语境**：即使前向拿到全局解，参数扰动下仍可能切换全局极小；QPEP 没有 corank=1 之类的稳定性证书，只能靠 gap/条件数监控并降级。

## 6. 建议的下一步

1. **先做"小规模、低维"的端到端验证**：PnP/点到面，$n=4$ 元数、$N\le 100$，用本报告的 full KKT 反向；验证外层训练（例如标定一个内参/权重）能否收敛。
2. **把诊断量做成 API**：`kkt_res`、`cond(M)`、`loss_gap`、`second_best`、`sos_min`、`lambda`；任何一项越界就返回"不可信梯度"标志。
3. **再决定是否要 full 枚举**：如果 596 模板能在目标平台上稳定工作，用"full 枚举 + 比较"替换"四支 + loss 比较"，全局性更强；否则保持"四支 + LM + gap 诊断"。
4. **与 SDPR 混合**：对能写成齐次 QCQP 的子问题，用 SDPR 的证书做交叉验证；用 QPEP 做初值/快速路径。两条路线的梯度应当在小扰动下一致，这本身是一个强验证。
