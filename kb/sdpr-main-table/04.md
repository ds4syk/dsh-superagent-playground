# 04 文献范式：七篇论文的主表怎么排

> **结论先行**：主表有两种范式。**应用型**（SPEED+/SPNv2、事件卫星）把“域”作为一级列，比领域指标 + SOTA + 消融；**方法型**（SDPRLayers、PnP*、Building Rome）把“正确性/最优性”和“效率/可扩展性”单独成表，精度只是应用展示。你的新方法如果同时声称“更准”和“可认证”，两张范式都要借。

## 如果只记三件事

1. **应用型主表**：行 = 方法，列 = 域 × 指标（`ET`/`ER`/`Epose`），再加消融与真实数据。
2. **方法型主表**：行 = 方法，列 = 最优性保证/rank-1 率/suboptimality + 时间/规模，精度放在第二张表。
3. **可认证 + 应用**：必须有一张“证书随训练/随域变化”的表或图，否则“certifiable”只是形容词。

## 0. 口径

以下数字均来自各论文公开版本（arXiv/DOI）；只做表格结构归纳，不复述全部实验。

## 1. SDPRLayers（T-RO 2025，arXiv:2405.19309）——方法型

**主表结构**：

| 表 | 行 | 列 | 回答 |
|-|-|-|-|
| Table III/IV | 方法（SVD、TheseusGT-UR、SDPR） | Jacobian 相对误差 | 梯度是否正确 |
| Table V | Theseus-RND、Theseus-GT、SDPR-IS | final baseline error、std、outer iterations、outer loss | 初始化/局部解是否毁掉标定 |
| Table VI/VII | Baseline、Baseline+VGG16、Ours | inliers、long/lat position error、heading error、inference time | 真实管线上的精度与代价 |

**关键数字**：Table V 中 Theseus-RND 的最终基线误差 `1.132e-1`，Theseus-GT 与 SDPR-IS 分别为 `3.463e-4`、`3.454e-4`；Table VI 中 Ours 的纵向误差 `0.035 m` vs `0.125/0.209 m`，推理时间 `0.243 s` vs `0.133/0.052 s`。

**对你的启示**：方法型论文不靠“刷点”立论，而靠“梯度正确性 + 初始化鲁棒 + 代价可接受”。你的 T3/T4 应该借这个结构：先把“可认证”变成可测量的量，再谈精度。

## 2. PnP*（2026，arXiv:2610.31797）——方法型

**主表结构**：

- **噪声 sweep 图**：横轴像素噪声 σ，纵轴分别为 MLE 目标值、rank-1 率、相对 suboptimality、旋转/平移误差、求解时间。
- **可扩展性图**：横轴点数 N，比较 SDP、Chordal-SDP、Reduced-SDP、BnB 的目标值、rank、运行时间。
- **baseline**：P3P、EPnP、EPnP+LM、SQPnP、Alternative、BnB。

**关键结论**：PnP* 比局部非最小解慢约三个数量级，但比 BnB 快 3–13 倍；松弛在 σ 到 10 px 时仍 exact，N≥6 时 40/40 rank-1。

**对你的启示**：如果新方法是“层/求解器”型，主表必须有 **noise sweep + rank-1/suboptimality + runtime vs N** 三件套；只报一个数据集上的精度，方法型审稿人不会买账。

## 3. SPEED+（2022，arXiv:2110.03101）——数据集/应用型

**主表结构**：

| 表 | 行 | 列 |
|-|-|-|
| Table 3 | SPN、KRN、HigherHRNet+EPnP | synthetic/lightbox/sunlamp × `ET`(m)/`ER`(°)/`Epose` |
| Table 4 | KRN + style aug / DANN / oracle | lightbox、sunlamp、prisma25 × 同指标 |

**关键设定**：synthetic train 47,966 / val 11,994；lightbox 6,740；sunlamp 2,791；`Epose = ER + ET/||t||`；SPEC2021 用 `θq=0.169°`、`θt=2.173 mm/m` 的修正。

**对你的启示**：领域主表的一级列是**域**，不是“平均”；只报一个域会被认为避开了 sunlamp 这个真正的难点。

**主表结构**：

| 表 | 数据 | 列 |

## 8. 两类范式的总结

| 维度 | 应用型 | 方法型 |
|-|-|-|
| 一级列 | 域（Lightbox/Sunlamp/真实） | 正确性/最优性 + 规模 |
| 主指标 | `ET`/`ER`/`Epose` | rank-1、suboptimality、time |
| baseline | 领域 SOTA + 几何 | 同层求解器 + 局部/全局对照 |
| 消融 | 组件、增广、backbone | 初始化、tightness、稀疏化、fallback |
| 真实数据 | 必须（prisma25/SPEED） | 可选（应用展示） |
| 常见死法 | 只报一个域、baseline 太少 | 只报精度、无证书/时间 |

**建议**：你的论文如果定位为“spacecraft 新方法”，主表按应用型排，但把 T3（证书/效率）放进正文——这是区别于普通“换个 backbone”的关键。如果定位为“SDPR 层改进”，主表按方法型排，spacecraft 只作为应用展示。
