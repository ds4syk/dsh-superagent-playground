## 1. 任务与数据集

### T1 桌面操作 6-DoF 位姿（主任务，$p=8\sim64$）

| 项 | 设定 |
|---|---|
| 数据集 | **YCB-Video (BOP 格式)**：21 个物体、92 段视频、约 13 万帧；取官方 train/test 划分。**LINEMOD / LINEMOD-Occlusion**：13 个物体，用于与 EPro-PnP/BPnP 的可比性。 |
| 支撑平面 | 每帧由深度图 RANSAC 拟合（或仿真真值），**在整段视频内固定**（这是"刚体桌面参数"假设，与 §4.5 的相容性论证对应）。 |
| 约束构造 | 物体网格的**凸包**在平面下方的顶点贡献非穿透约束；$p$ 由"下包络顶点数"决定，通过取凸包 vs 取全部顶点控制 $p\in\{8,16,32,64\}$。所有观测关键点加正深度约束（$z_{\min}=0.05$ m）。 |
| 网络 | 与 SDPRLayers/BPnP 同构的 keypoint 回归骨干（ResNet-18 或 VGG16 + 双 UNet，参照本仓库 `kb/sdpr-forward-net/01.md` 的 In-The-Dark 管线改 6-DoF 输出）。**同一骨干、同一训练计划，只换层**。 |
| 监督 | 仅位姿监督（ADD 或 $L_2$），不加穿透惩罚——否则无法区分"层的约束"与"损失函数的约束"。 |
| 指标 | **ADD(-S)**（mm）、ADD(-S) $<2$ cm 的比例、**穿透深度** $\max_v[\mathbf n^\top(\mathbf R\mathbf v+\mathbf t)+d]_-$（mm，取每帧最大值再平均）、**穿透比例**（$>1$ mm 的帧占比）、**前向/反向延迟**（ms/pose，CPU 单核 + GPU batch）。 |
| 规模 | 全量 test 或官方指定的 1000 帧子集；报告帧数。 |

### T2 带物理先验的定位（第二任务，与 SDPRLayers 直接对齐）

| 项 | 设定 |
|---|---|
| 数据集 | **UTIAS In-The-Dark**（与 SDPRLayers §VI-C 完全一致的双目管线与划分，100k/20k）；**KITTI odometry**（地面车，倾角锥 $\alpha=10^\circ$ + 正深度）；**TUM RGB-D**（手持，仅正深度）。 |
| 约束 | KITTI：横滚/俯仰锥（4 条不等式，或用 $q_1^2+q_2^2\le\sin^2(\alpha/2)$ 一条）+ 全部特征点正深度。TUM：正深度。UTIAS：正深度 + FoV（相机标定已知）。 |
| 指标 | 平移/旋转 RMSE（m/deg）、约束违反率、**证书紧的比例**、延迟。 |
| 公平性 | UTIAS 必须复现 SDPRLayers 的网络与训练设置（本仓库已有该管线的精读记录 `kb/sdpr-forward-net/01.md`）；KITTI/TUM 用同一前端（SuperPoint+SuperGlue 或 ORB，固定）只换后端层。 |

### T3 等式+不等式混合（校准类，展示通用性）

| 项 | 设定 |
|---|---|
| 任务 | 手眼标定 / 点到面配准，加关节限位（倾角锥）先验；沿用 QPEP 的问题族。 |
| 目的 | 证明层不只处理 PnP；同时展示等式约束可以写成两条不等式（若实现上更方便）。 |
| 指标 | 标定误差、约束满足率、耗时。 |

### 数据规模与划分（防泄漏）

- YCB-Video：官方 train/test，**不在 test 上调任何超参**；超参（$\rho_0$、$\varepsilon$ 系数、$\delta_{\rm act}$）在 train 的 5% 上选。
- UTIAS：官方划分；若需验证集，从 train 切 5%。
- KITTI：序列 00–10 训练/验证，11–21 测试（标准划分）。

## 2. Baseline

| # | 方法 | 版本/来源 | 施加约束的方式 | 公平性说明 |
|---|---|---|---|---|
| B1 | **SDPRLayers**（无约束） | 官方 `utiasASRL/sdprlayer` | 无 | 同网络同训练，仅层不同。注意本仓库知识库记录其在 SCS 3.3.1 下有 28% 求解失败，需启用自适应容差重试（patch 已入库）。 |
| B2 | **SDPRLayers + $p$ 个 slack** | 自实现（其官方不支持不等式） | 松弛变量，$(10+p)\times(10+p)$ | 必须报告 tightness 率与耗时；这是 Q-D 的关键证据。 |
| B3 | **Theseus** | 官方 | 软惩罚（Huber/二次），扫权重 $\lambda\in\{10^{-2},10^{-1},1,10,10^2\}$ | 报 Pareto 曲线（穿透 vs ADD），不报单点。 |
| B4 | **dQP + 局部线性化（SCP）** | 官方 + 自写 SCP 外壳 | 每步线性化旋转后解凸 QP | 这是"最强的凸层 baseline"；报迭代次数与总耗时。 |
| B5 | **QPEP（无约束）+ 事后投影** | 官方 `LibQPEP`（C++/MATLAB） | 解完再投影到可行集 | 隔离"解约束问题"与"修无约束解"的差别。 |
| B6 | **Ours** | 本仓库 | 硬约束 + ALM + FB 反向 + 后验证书 | — |

**统一规定**：
- 所有方法用**同一套 2D-3D 对应**（同一前端输出），避免前端差异污染。
- 所有方法报**同样的指标**（ADD(-S)、穿透、延迟），并给出 3 个随机种子的均值±标准差。
- 延迟必须在**同一硬件、同一 batch size、warm-up 后**测量；CPU 与 GPU 分开报。

## 3. 指标定义（写进论文，避免歧义）

1. **ADD(-S)**：对称物体用 ADD-S（最近点距离），非对称用 ADD；单位 mm。
2. **穿透深度**：$d_{\rm pen}=\max_{v\in\mathcal V}\big([\mathbf n^\top(\mathbf R\mathbf v+\mathbf t)+d]_-\big)$，$\mathcal V$ 为物体网格顶点，$(\mathbf n,d)$ 为支撑平面。单位 mm。**注意**：这只测"物体在支撑面下方"的部分，不测物体间互穿。
3. **穿透比例**：$d_{\rm pen}>1$ mm 的帧占比（%）。1 mm 阈值按典型 RGB-D 噪声设定，需在论文里说明理由。
4. **约束违反率**：$\max_j[g_j]_+>\nu_{\rm tol}$ 的帧占比；$\nu_{\rm tol}=10^{-6}$（按物理量纲：m 或无量纲）。
5. **证书紧率**：$14\times14$ SDP 的 $\lambda_2/\lambda_1\le10^{-6}$ 且 $|J(\hat z)-\mathrm{Shor}|\le10^{-6}$ 的帧占比。
6. **延迟**：前向（含内层迭代）、反向、证书三部分分开计时。
7. **条件数**：$\kappa(\mathbf S)$ 的分布（中位数、95 分位、最大值）。

## 4. 消融

| # | 消融 | 变量 | 想回答的问题 | 预期（可被推翻） |
|---|---|---|---|---|
| A1 | GN vs 精确 Hessian | 式 (9a) vs Remark 4.1 | GN 偏差多大？ | GN 偏差在训练中可忽略（<5% ADD），但单步梯度差 $O(\mu\|\nabla^2g\|)$ |
| A2 | FB $\varepsilon$ | 固定 $10^{-6}$ / 自适应 $c\mu$（$c=10^{-4}$）/ 无正则（硬活跃集） | $\varepsilon$ 敏感性；硬活跃集是否崩 | 硬活跃集在秩亏处产生 NaN/奇异；自适应最稳 |
| A3 | 证书 | 开/关 | 证书的成本与它对指标的影响 | 证书不影响精度，只增加 $O(p\cdot14^3)$ 的后验成本 |
| A4 | 内层求解器 | QPEP 型多项式枚举 vs 多起点局部优化 | "枚举"值多少 | 枚举在歧义/接触构型上显著更稳（预期差距最大的一项） |
| A5 | 约束数量 $p$ | $8/16/32/64$ | 成本曲线与精度曲线 | 成本线性于 $p$（装配）+ 常数（求解）；精度在 $p\ge16$ 后饱和 |
| A6 | $\rho$ 调度 | $\times2/\times5/\times10$，上限 $10^2/10^3/10^4$ | 收敛 vs 数值稳定 | $\rho\le10^3$ 稳，$\rho=10^4$ 起内层条件数恶化 |
| A7 | 约束类型 | 仅深度 / 仅非穿透 / 全部 | 哪类约束真正起作用 | 非穿透是主要贡献（深度约束在多数帧不活跃） |

## 6. 复现风险（按严重度）

| # | 风险 | 影响 | 缓解 |
|---|---|---|---|
| R1 | **QPEP 模板不能直接复用**（Q1） | 前向常数变大 2–4 倍；"用现成 QPEP"的叙事失效 | 先做 Q1 的根数统计（1 周）；Plan B 重新生成模板（1 周）；论文改口径为"同一代数族" |
| R2 | **$14\times14$ 松弛在真实数据上不紧** | "certifiable" 降级为 "sound bound" | 已在 §6 写好降级叙事；实验把紧率作为一等结果报告；若紧率 <50%，论文标题去掉 "certifiable" |
| R3 | **YCB-V 支撑平面假设不成立**（堆叠物体、斜面） | T1 的部分帧约束错误，指标失真 | 按场景分层报告；只用"单物体在平面上"的子集做主表；堆叠场景单列 |
| R4 | SDPRLayers 官方代码不稳定（知识库记录 28% 失败） | baseline 数字不可比 | 用已入库的容差重试 patch；报告失败率；若仍不稳，用 B2 自实现作主对比 |
| R5 | 深度噪声导致"伪穿透" | 穿透指标被噪声主导 | 同时报"相对穿透"（穿透/物体尺寸）与"仅深度真值帧"的子集指标 |
| R6 | 端到端训练不稳定（ALM 内层不收敛） | 训练崩 | 记录每步外层迭代数与残差；设最大迭代与 fallback（B5 的投影解）；在 A6 里量化 |
| R7 | $\varepsilon$ 与 $\rho$ 的耦合 | 复现者调不出同样结果 | 论文给完整调度公式（$\varepsilon=c\mu$，$c=10^{-4}$；$\rho$ 倍增规则），并附敏感性图 |
| R8 | 前端差异污染对比 | 审稿人质疑公平性 | 固定同一前端输出，公开对应文件 hash |
