# 01 主流方案地图：从“写证明”到“验证明”

> **结论先行**：当前 AI 做数学证明不是“一个模型端到端”，而是六类方案按可靠性分层：
> 通用长思维链模型负责探索与草稿；Lean/Coq/Isabelle 负责机器可检验；智能体负责长程编排；
> 自动形式化负责自然语言到形式语言的桥；CAS/数值/SAT 负责有限验证；人机协作负责最终可信。
> 越往后越可信，也越贵。

**如果只记三件事**：

1. 竞赛题/教材题：通用模型 + 自审已经很强；研究级问题：仍需要“模型探索 + 专家/Lean 验证”。
2. 形式化不是可选项而是“可信交付”的核心；但它只覆盖能被形式化的部分，且成本高。
3. 工具增强能显著改变“能不能验证”，但改变不了“有没有想法”；瓶颈通常在提出关键引理。

## 0. 口径

| 方案 | 输入 | 输出 | 正确性保证 |
|---|---|---|---|
| 通用长思维链 | 题面/文献 | 自然语言证明 | 人工评审 |
| 形式化证明 | Lean 命题 | Lean 证明项 | 内核检查 |
| 智能体搜索 | 题面 + 工具 | 证明/反例/部分结果 | 工具 + 评审 |
| 自动形式化 | 自然语言 | 形式命题/证明骨架 | 人工校对 + 内核 |
| 工具增强 | 有限/符号问题 | 计算证书/反例 | 可复现计算 |
| 人机协作 | 以上全部 | 可信研究产出 | 社区/专家 |

## 1. 六类方案

### 1.1 通用长思维链模型（natural-language proof）

**代表**：OpenAI o1/o3/GPT-5 系列、DeepSeek-R1/V3/V4、Kimi K1.5/K2/K3、Gemini Deep Think、
Claude 扩展思考。

**做法**：长上下文 + 长思维链；读题、找类比、写证明、自审；可选用 Python/检索。

**强项**：覆盖面最广；能处理“有标准套路”的竞赛题；能读论文、写自然语言；成本相对低。

**弱项**：正确性无机器保证；长证明中段容易出错；研究级问题容易“把猜想当定理”；需要专家评审。

**证据**：
- IMO 2025：MathArena 统一协议下公开模型最高 31.55%（Gemini 2.5 Pro），不到铜牌；厂商未公开
  模型声称金牌。[MathArena](https://matharena.ai/imo/)
- FrontierMath（2026-11 快照）：GPT-5.5 Pro 52.4%、Kimi K2.6 38.97%、DeepSeek-V3.2 22.1%。
  [evals.report](https://evals.report/benchmarks/frontiermath)

### 1.2 形式化证明（Lean/Coq/Isabelle + RL/LLM）

**代表**：AlphaProof（Nature 2025）、DeepSeek-Prover-V2、Kimina-Prover、Goedel-Prover、
LeanDojo、COPRA、Aristotle。

**做法**：把定理写成形式命题；模型生成 tactic/term；编译器反馈；树搜索/RL；Mathlib 提供引理库。

**强项**：内核检查，正确性最高；可复用 Mathlib；适合“可信交付”。

**弱项**：形式化成本高；Mathlib 覆盖有限；自动形式化瓶颈；研究级定理的形式化可能极长；
RL 系统常绑定特定版本/工具链。

**证据**：
- AlphaProof：AlphaZero 风格 RL + 百万级自动形式化题；IMO 2024 解出 3/5 非几何题，银牌级。
  [Nature](https://www.nature.com/articles/s41586-025-09833-y)
- DeepSeek-Prover-V2：MiniF2F-test 88.9%，PutnamBench 49/658。[arXiv](https://arxiv.org/abs/2504.21801)
- PutnamBench：1692 个形式化 / 640 道 Putnam 题；当时神经/符号证明器只能解“handful”。
  [arXiv](https://arxiv.org/abs/2407.11214)
- LeanDojo：检索增强 Lean 证明；证明搜索需要 premise retrieval。[arXiv](https://arxiv.org/abs/2306.15626)

### 1.3 智能体与搜索（agentic proof search）

**代表**：AlphaGeometry（几何专用）、GPT-f、COPRA、LeanCopilot、Aristotle、各家 deep-research
式长程智能体。

**做法**：规划 → 子目标分解 → 工具调用 → 验证 → 修复；多智能体分工；记忆/检索。

**强项**：长程、多步、需要工具；比单次生成稳；可形成“提出—验证—修复”闭环。

**弱项**：编排复杂；错误级联；成本高；不同 scaffold 不可比；容易“看起来很忙”。

### 1.4 自动形式化与证明修复

**代表**：Wu et al. 2022、LeanCopilot、LeanDojo 生态、2025-2026 的 agentic autoformalization。

**做法**：自然语言题面 → 形式命题；证明草图 → tactic；编译错误 → 修复；`sorry` → 子目标。

**强项**：把人类可读数学转成机器可检验对象；是“自然语言 + Lean”的桥。

**弱项**：题面翻译错误比证明错误更隐蔽；需要专家校对；非标准记号/定义难。

### 1.5 工具增强（CAS/数值/SAT/图搜索）

**做法**：数值实验找反例/猜公式；符号计算验证恒等式；SAT/SMT/ILP 解有限存在性；图搜索/
枚举极端构型；区间算术严格化。

**强项**：把有限可验证部分剥离；快速否证错误猜想；给证明提供可复现证据。

**弱项**：不能替代一般性证明；数值证据不是证明；工具/版本/精度会引入新错误。

### 1.6 人机协作与验证流水线

**做法**：AI 草稿 → 专家评审 → Lean 形式化关键部分 → 独立复现/审计 → 版本化。

**关键点**：AI 生成 ≠ 已验证。可信交付需要：明确假设、可追溯证据、独立复核、证据分级。

## 2. 方案选择：按问题类型

| 问题类型 | 首选 | 次选 | 不建议 |
|---|---|---|---|
| 竞赛题/教材题 | 通用长思维链 | 形式化（若需严格） | 重型智能体 |
| 研究级猜想（有明确命题） | 通用模型 + 专家 | 智能体 + 工具 + Lean | 单次生成即当真 |
| 有限组合/反例搜索 | 工具增强 + 通用模型 | 智能体 | 纯自然语言 |
| 需要可信交付的定理 | Lean + 自动形式化 + 专家 | 形式化 + 独立审计 | 只发自然语言 |
| 跨领域文献综述 | 通用模型 + 检索 | 智能体 | 无检索的闭卷 |

## 3. 成本与可靠性

- **可靠性排序**（经验）：Lean 内核检查 > 独立复现的计算证书 > 专家逐行评审 > 模型自审 >
  单次生成。
- **成本排序**：形式化/自动形式化通常最贵；通用模型最便宜；工具/智能体介于两者之间。
- **研究级问题**：成本主要花在“试错 + 验证”，不是“生成”；OpenAI 722 篇平均 3 小时
  ChatGPT Pro thinking/结果，且仍有撤回/修订。
