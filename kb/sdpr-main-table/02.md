# 02 Baseline 分层与可复现性

> **结论先行**：baseline 要三层同时在场——经典几何（证明几何本身没问题）、可微与可认证几何（分离“全局性”的贡献）、领域 SOTA（证明在任务上有效）。只跟 SPNv2 比，审稿人会问“你的提升是不是换个检测器就有”；只跟 EPnP 比，又无法证明方法有价值。

## 如果只记三件事

1. **每个新方法至少要有两个“同层”对手**：SDPR 层改进要跟 SDPRLayers、PnP*、Theseus、EPro-PnP 比；spacecraft 前端要跟 SPNv2、KRN、UDA、StructGCN 比。
2. **直接前身必须复现**，不能只引用论文数字；协议不同（crop、输入分辨率、训练数据、是否用 HIL 标签）时，引用数字只能放“参考”而不能放主表。
3. **可认证方法的对照要选“局部但同样可微”的方法**（Theseus、EPro-PnP），才能把“全局最优/证书”的贡献与“端到端训练”分开。

## 0. 口径

- SDPRLayers 的代码与实验协议：arXiv:2405.19309；层仓库 `utiasASRL/sdprlayer`，论文管线在 `utiasASRL/deep_learned_visual_features` 的 `mat-weight-sdp-version` 分支。
- PnP*：arXiv:2610.31797；代码 `github.com/doggydoggy0101/pnp-star`。
- SPNv2 / KRN 的协议与数字：SPEED+（arXiv:2110.03101）与 SPNv2（arXiv:2203.04275）的表格。
- 开源状态为 2026-11-09 的公开检索结果，未逐一 clone 验证；复现前先确认分支与 commit。

## 1. 三层 baseline 清单

### 第一层：经典几何（sanity floor）

| 方法 | 作用 | 输入/输出 | 注意 |
|-|-|-|-|
| **EPnP + LM** | 非最小 PnP 的标准解，几乎所有 two-stage 管线的默认 | 2D-3D 对应 → 位姿 | 需要好的 2D 检测；LM 精化后不保证全局 |
| **SQPnP** | 全局最优的代数 PnP（最小二乘意义） | 2D-3D → 位姿 | 与 EPnP 同表可显示“几何求解器不是瓶颈” |
| **P3P + RANSAC** | 最小解 + 鲁棒估计 | 3 对点 → 位姿 | 外点场景的强基线；RANSAC 迭代次数要固定 |
| **SVD / ICP** | 3D-3D 配准（若方法用深度） | 3D-3D → 位姿 | 与 SDPR 的 matrix-weighted 版本对比 |

### 第二层：可微与可认证几何（方法价值的直接对照）

| 方法 | 类型 | 为什么必须 | 复现注意 |
|-|-|-|-|
| **SDPRLayers** | SDP 松弛 + 隐式微分，可认证 | 直接前身；不复现就无法声称“改进” | scalar 与 matrix-weighted 两种都要；Mosek/SCS 求解器要写明；`ba66e408` 分支含完整管线 |
| **PnP\***（2026） | 可认证 PnP MLE（chordal 稀疏 + 降阶） | 若你的方法是 PnP 型，这是最强的可认证对手 | 官方代码；报告 rank-1 率与 solve time；注意它优化 MLE，与“替代误差”方法不同 |
| **EPro-PnP** | 可微概率 PnP | 端到端可微 PnP 的强基线，分离“概率建模”与“可认证” | 需要 2D-3D 对应与 CAD 模型；官方代码 |
| **BPnP** | 可微 PnP（隐式微分） | 经典可微几何基线，计算便宜 | 局部解；与 SDPR 的差异正是“全局 vs 局部” |
| **Theseus** | 可微非线性优化库 | 局部可微优化的代表；SDPRLayers 论文的主要对照 | 初始化敏感；随机初始化会暴露局部极小 |
| **UDA 的 diff-PnP 头** | 可微 PnP + 3D 对齐损失 | 领域内已有的“端到端几何”基线 | 与 SPNv2 同属你草稿的 baseline，保留以连贯 |

### 第三层：领域 SOTA（证明任务上有效）

| 方法 | 类型 | 备注 |
|-|-|-|
| **SPNv2-H** | heatmap + PnP | SPEED+ 上的主 SOTA，必须复现或引用同协议数字 |
| **SPNv2-E** | 直接回归分支 | 同一网络的两个分支，用来显示“几何头”相对“直接回归”的增益 |
| **KRN**（2019） | 关键点回归 + 非线性精化，需 perfect bbox | 历史基线；SPNv2 表里 KRN 的 `ER` 为 44.53°/80.95°，只能作弱参照 |
| **UDA**（2023） | 2D/3D 结构损失 + 无监督域适应 | 领域内强域适应基线；开源状态需确认 |
| **StructGCN**（2026） | 结构感知图卷积 | 新近 SOTA；若无可复现代码，引用其自报数字并标注协议 |
| **Wang 2022 Transformer** |  Transformer 前端 | 显示 backbone 不是唯一变量 |
| **Wang 2023 自训练** | 几何约束伪标签 | 域适应强基线；与你的 HIL 标签设定可能冲突，注意区分 |
| **SPEC2021 前排方案** | 竞赛方案 | 只作参考，协议/集成细节常不完整 |

## 2. 怎么选：一张决策表

| 你的创新点 | 必选 baseline | 建议补充 | 可省略 |
|-|-|-|-|
| SDPR 层改进（tightness/效率/鲁棒） | SDPRLayers、PnP*、Theseus、EPro-PnP | BPnP、chordal/spectral、BAL/Replica 上的 COLMAP/GLOMAP | KRN、SPNv2 |
| spacecraft 新前端 | SPNv2-H/E、KRN、UDA、SDPRLayers | StructGCN、Wang 2022/2023、EPnP+LM、SQPnP | BAL/Replica |
| 事件/光照鲁棒 | SPNv2、事件方法、TTA 方法 | SPADES 上的 baseline、EPnP+LM | SfM 类 |
| V-JEPA2/表征桥接 | direct、two-stage、chordal、SDPR | KITTI/ETH3D 上的几何基线 | spacecraft SOTA |

## 3. 复现与公平性注意

1. **同一训练数据、同一 split、同一预处理**。如果某方法必须 crop，就在表注写“† perfect bbox”，不要悄悄给它更好的输入。
2. **同一评测脚本**。`Epose`、`ET`、`ER` 的实现要一致；四元数符号、旋转矩阵投影、失败阈值都会影响数字。
3. **同一求解器设置**。SDPR 的 Mosek vs SCS、容差、是否 warm-start，都会改变 tight rate 与时间；表注写清。
4. **同一随机种子数**。至少 3 seed；baseline 只跑 1 次、你的方法跑 5 次取最好，是常见的隐性不公平。
5. **开源状态先验证**。很多领域论文没有完整代码；引用数字时注明“as reported”，不要伪装成自己复现。
6. **弱基线不要删**。KRN 很差，但它证明“这个任务本身很难”；删掉反而显得挑对手。

## 4. 一个最小可投稿组合

如果时间有限，优先保证这 8 个方法：

**EPnP+LM、SQPnP、SDPRLayers、PnP\*、EPro-PnP、Theseus、SPNv2-H、SPNv2-E**

再加你自己的 3–4 个变体（local solver 替换、random init、no precision、first-stage）。这套组合能同时支撑“几何有效”“可微有效”“可认证有代价”“领域 SOTA 可比”四条叙事。
