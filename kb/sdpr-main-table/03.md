# 03 主表模板：六张表

> **结论先行**：主表由六张表组成——主比较、尾部与失败、证书与效率、消融、鲁棒 sweep、跨数据集。前三张回答“比别人好吗、失败少吗、代价多大”，后三张回答“为什么好、在什么条件下好、换个数据还行吗”。每张表只回答一个问题，列不要互相重复。

## 如果只记三件事

1. **T1 用官方指标**（`ET`/`ER`/`Epose`），双域并列；不要只放相对平移。
2. **T2 是“可认证”方法真正的卖点**：RMSE、max、失败率；均值相同、尾部更短，才是全局最优性的价值。
3. **T3 是审稿人最先翻的表**：tight rate、certificate rate、solver ms、FPS；没有这张表，“可认证”只是口号。

## 0. 口径

- 表内数字为**格式示意**，取自你上传草稿的 Table I（`E2E_pose_est_v1.pdf`）与 SDPRLayers/SPNv2 的公开表；不是新实验结果。
- 单位：`ET` m，`ER` °，`Epose` 无量纲，时间 ms，FPS 帧/秒。
- 所有表共用同一训练集、同一 split、同一预处理；表注写清例外。

## T3 证书与效率：可认证性的代价

**回答**：松弛紧不紧？证书覆盖多少样本？每样本多花多少时间？端到端还能不能实时？

| Method | tight rate (%) | cert rate (%) | median solver ms | P95 solver ms | e2e FPS | params (M) |
|-|-|-|-|-|-|-|
| SDPRLayers | | | | | | |
| PnP\* | | | | | | |
| Theseus | | | | | | |
| EPro-PnP | | | | | | |
| Ours | | | | | | |

- **tight rate**：`λ₂/λ₁ < 1e-5` 或 rank-1 比例；写清判据。
- **cert rate**：对偶证书 `H ⪰ 0` 通过的比例；与 tight rate 分开，二者不一定相等。
- **solver ms**：只计 SDP/优化层，不含前端；median 与 P95 都给，P95 才能反映最坏情况。
- **e2e FPS**：含前端与后处理；注明 GPU/CPU、batch size。
- 若 SDP 是 CPU-only（SDPRLayers 的默认实现），FPS 会显著低于 GPU 前端；这正是要诚实报告的代价。

**示意**（SDPRLayers 论文 Table VI，常规测试集）：

| Pipeline | Long. err (m) | Lat. err (m) | Heading err (°) | Avg inf. time (s) |
|-|-|-|-|-|
| Baseline（SVD） | 0.209 | 0.134 | 0.414 | 0.052 |
| Baseline + VGG16 | 0.125 | 0.049 | 0.301 | 0.133 |
| Ours（SDPR） | 0.035 | 0.021 | 0.288 | 0.243 |

> 这张表的关键信息不是“更准”，而是“时间约为 SVD 的 2 倍、误差降一个量级”；你的 T3 也要给出这种“代价—收益”的对照。

## T4 消融：每个设计点是否必要

**回答**：精度提升来自哪个组件？关掉后 tight rate/证书是否崩？

| Config | ET↓ | ER↓ | Epose↓ | tight rate (%) | ΔEpose |
|-|-|-|-|-|-|
| Full | | | | | – |
| w/o precision matrix | | | | | |
| w/o depth | | | | | |
| first-stage only | | | | | |
| local solver（替换 SDPR） | | | | | |
| random init | | | | | |
| w/o bbox query | | | | | |
| 5/5 layers | | | | | |
| 7/7 layers | | | | | |

- 每次只关一个；Δ 相对 Full。
- **local solver / random init 这两行最重要**：它们直接检验“全局最优 + 可信梯度”是否真的带来差异；如果关掉 SDPR 也不掉点，那方法的核心贡献就不成立。
- 如果 tight rate 在某配置下降，必须同时报告 fallback 策略与 fallback 比例，否则数字不可信。

**示意**（草稿 Table III/IV 的消融口径）：

| Config | LB ER RMSE | SL ER RMSE | SL ER max |
|-|-|-|-|
| Full | 5.383 | 4.042 | 39.86 |
| w/o precision | 10.493 (+94.9%) | 12.598 (+211.7%) | 179.21 |
| first stage only | 7.465 (+38.7%) | 6.753 (+67.1%) | 91.84 |
| w/o bbox query | 7.753 (+44.0%) | 8.885 (+119.8%) | 146.45 |

## 表格自检清单

- [ ] 每张表有单位、聚合方式、seed 数。
- [ ] 每张表回答一个明确问题，列不重复。
- [ ] best/second 标注规则一致；不挑对自己有利的指标。
- [ ] 协议（crop、HIL 标签、输入分辨率、求解器）在表注写清。
- [ ] 失败率与 max 不被均值掩盖。
- [ ] 可认证方法给出 tight/cert rate 与 fallback 策略。
- [ ] 时间给出 median 与 P95，不只给平均。
- [ ] 跨数据集表区分 inductive/transductive。
