# 清晨海边灯塔小渔港

一个用 Three.js（r128，经典 `<script>`，非 ES module）程序化生成的 360° 沉浸式全景三维场景：
清晨的渔港木栈桥、北侧岬角上的红白条纹灯塔、南侧停泊的渔船、西侧山坡上的彩色小屋与松林。

**双击 `index.html` 即可打开**，离线可运行，无需任何本地服务器；所有贴图与模型均由代码生成，不依赖外部图片或模型文件。

---

## 打开与操作

| 操作 | 效果 |
|-|-|
| 双击 `index.html` | 直接在浏览器打开（file:// 协议可用） |
| 鼠标拖拽 / 单指滑动 | 360° 环视（水平不限，俯仰约 -68°～+54°） |
| 滚轮 / 触控板双指 | 调整视野远近（FOV 30°～78°） |
| `WASD` / 方向键 | 在栈桥与岸边小幅走动（限幅，走不出场景） |
| 静止约 5 秒 | 视角缓慢自动环视（任意操作立即停止） |

页面内没有任何 UI：无标题、按钮、提示、水印、加载文字，只有一块全屏画布。

## 程序化与确定性

- 随机数统一来自 `00-utils.js` 的 mulberry32，种子 `LH.SEED = 20261110`；同一份代码每次打开得到完全一致的树木位置、纹理噪点与船只姿态。
- 木纹、岩石、沙粒、抹灰、瓦片、锈铁、石墙、灯塔条纹、渔网、贩卖机面板、草叶等贴图全部由 Canvas 2D 在运行时绘制。
- 船体是按截面参数生成的网格；地形是按解析高度场生成的网格；灯塔、房屋、码头由基础几何体组合并倒圆角。

## 四向构图

- **东**：开阔海面延伸到海平线，低角度朝阳、太阳反光带、远处岛屿剪影、红绿浮标、出海渔船。
- **北**：突出的岬角礁石上是红白条纹灯塔（灯室、围栏阳台、旋转光束）与守塔人小屋（亮窗、烟囱炊烟）。
- **南**：渔港海湾，三艘侧泊渔船随浪晃动，系船桩与缆绳、防波堤与堤头灯桩、渔网晾晒架、木箱浮球、渔具仓库。
- **西**：沙滩、彩色海边小屋沿山坡排开，松树、电线杆与下垂电线、自动贩卖机、木栅栏，身后是起伏的绿色山丘。

## 性能与实现

- 约 36 万三角面、100 余次绘制调用；海面近处 300×300 细分做真实起伏，远处环形平面靠法线细节与菲涅尔。
- 光照：低角度暖色平行光（2048 阴影贴图、软阴影）+ 半球天光 + 逆光补光；海面与天空共用同一段 GLSL 天空函数，保证反射一致。
- 后期：SSAO 环境光遮蔽 → 泛光 → 远景景深 → 胶片颗粒 → 清晨色彩分级/暗角 → 伽马输出。
- 设备像素比上限 1.5；窗口缩放自适应。

## 调试参数（可选，不影响默认浏览）

`index.html?yaw=90&pitch=-2&fov=58&x=-4&z=0&post=1&ao=1&dof=1&bloom=1&shadow=1&auto=1`

- `yaw` / `pitch`：初始朝向（度）
- `fov`：初始视野
- `x` / `z`：初始位置（限定在栈桥/岸边）
- `post=0`：关闭后期；`ao` / `dof` / `bloom=0`：单独关闭某个后期环节
- `shadow=0`：关闭阴影；`auto=0`：关闭静止自动环视

## 自检

- 控制台零报错（Chrome 无头 + 软件 WebGL 逐帧检查）。
- 四方向截图见 `shots/`（由 `?auto=0` 固定视角采集，仅用于验收，不进入页面）。
- 离线验证：全部脚本与依赖都在本地目录内，页面不发起任何外部请求。

## 已知限制

- 需要支持 WebGL 的现代浏览器；极老设备可能无法开启后期链。
- 场景以“写实偏暖的治愈插画风”为目标做了风格化取舍（低面数远景、程序化贴图），并非照片级渲染。
- 后期中的 SSAO 与景深会额外渲染场景，低端集显上帧率会下降；可用 `?post=0` 对比。
