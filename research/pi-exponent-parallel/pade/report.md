> 本文件是并行深挖窗口（方向：Padé / Salikhov / Rhin–Viola 型整系数线性型）的交付物。
> 只使用一般数学文献与经典方法（Padé 逼近、Gauss–Legendre 求积、连分数、Beukers 型重积分、
> lcm 分母估计、整数 Chebyshev / 容量论证）；未使用任何 Family 017 专用材料。

## 结论先行

1. **[证明] 归约引理完全建立。** 若存在整系数线性型 `F_n = α_n + β_n π` 满足
   `|F_n| ≍ A^{-n}`、`|β_n| ≤ B^n`，则对任意 p/q，
   `|π − p/q| ≥ c q^{−(1+log B/log A)}`，即 `μ(π) ≤ 1 + log B/log A`；
   等价地 `μ(π) ≤ 2 + log ϱ / log(1/|F_n|)`，其中
   **`ϱ_n := |F_n|·|β_n|`（形式的质量）**。因此
   **`ϱ_n ≤ 1+o(1)` ⟹ `μ(π) ≤ 2`；反之任何成功的族都必须让 `ϱ_n` 的增长被 ε 吃掉。**
   例外有理数（`p/q = −α_n/β_n`）不需要"双族"假设：对每个固定的有理数只有有限多个 n 例外，
   而选取的 n(q) → ∞，故大 q 自动避开；小 q 有限个，逐例可查（[证明]，§2.2）。

2. **[计算] 关键恒等式：质量分解为"内在质量 × 分母平方"：**
   `ϱ_n = D_n² · |ℓ_n| · |b_n|`（`ℓ_n = a_n + b_n π` 的有理系数形式，`D_n` = 清分母因子）。
   **所以整个 μ(π) ≤ 2 问题的瓶颈可以完全定位到分母上**：需要
   `D_n ≤ D*_n := (|ℓ_n|·|b_n|)^{-1/2}`。这是本文的核心定量结论。

3. **[计算] 三条具体路线的实测数据（全部精确计算、高精度复核）：**

   | 路线 | 内在质量 `|ℓ_n||b_n|` | `D*_n` 的底 | 实际 `D_n` 的底 | 判定 |
   |---|---|---|---|---|
   | arctan 的 Padé（在 x=1 取值） | `16^{-n}`（超 Dirichlet 16 倍） | `4^n` | `≈95^n` | 差 `24^n`，失败 |
   | 正权单积分 `∫(x(1−x))^n/(1+x²)` | `≈2^{-1.5n}` | `1.68^n` | `≈6.2^n` | 差 `3.7^n`，失败 |
   | π 自身连分数收敛子 | `q_k|q_kπ−p_k| < 1`（Dirichlet 最优） | `≥1` | `D=1`（整数！）| **通过**，仅剩例外 |

4. **[计算] arctan–Padé 的精确衰减常数是 `4(3+2√2) = 4(1+√2)² = 23.31`，并精确分解为
   "质量因子 `4^{-n}` × Legendre 增益 `(1+√2)^{2n}`"**（比值收敛到 `(3+2√2)^{-n}`，见 §4.3）。
   这是"超 Dirichlet 质量"的来源；但 `D_n ≈ 95^n` 把它彻底吃掉。

5. **[证明+计算] 正权单积分族：严格的衰减上限 + 精确的分母阈值。** 若权 `W ≥ 0`（整数系数），则
   `|L| = ∫W/(1+x²) ≥ (1/2)∫W = (1/2)B(n+1,n+1)`，即衰减**不可能快于 `4^{-n}`**（[证明]）。
   把该族的指数写成 `D_n` 的显函数后，`μ ≤ 2` 恰好等价于
   **`D_n ≤ 4^{3n/8} = 1.68^n`**；实测 `D_n ≈ 10^{0.79n} = 6.2^n`，**差 3.66^n**。
   而 lcm 税 `e^{2n} = 7.39^n > 4^n` 解释了为什么实测分母必然停在这个量级。
   **`4 < e²` 是这类构造的结构性死因（[分析]）。**

6. **[计算] 二维 Beukers 角点机制确实能战胜 lcm 税**（衰减底 `≈11.09`，Richardson 外推，
   `> e² = 7.39`），**但其值必属 `ℚ + ℚ·ζ(2)`**（[证明]：被积项是完全平方 ⇒ 部分分式只有二阶极点
   ⇒ 只出现 `ζ(2)`）。所以它给的是 `μ(π²)`，转换为 `μ(π)` 要付因子 2：
   `μ(π) ≤ 2μ(π²) = 10.88 > 7.6063`。**这是二维路线的精确障碍。**

7. **最终判定：** 本方向**不能**证明 `μ(π) ≤ 2`，且障碍已精确量化到单一常数（见 §6 的四条必要条件
   C1–C4 与差距表）。唯一在定量上"够格"的族是 π 自身的连分数收敛子（整数、质量 < 1），
   它的障碍恰好是经典的**例外有理数 + 部分商增长**：
   `μ(π) ≤ 2 + limsup_k log a_{k+1} / log q_k`（[证明]）。我们算了 π 的前 ~900 个部分商：
   `k ≥ 50` 时该量 ≤ 0.014（即条件指数 ≤ 2.014），但"对所有 k"的陈述无法证明
   （这正是 π 部分商不受控这一经典未知）。

## 1. 问题与出发点

目标：证明对任意 ε>0、所有整数 p、q>0，
`|π − p/q| ≥ c_ε q^{−2−ε}`，即 `μ(π) ≤ 2`。

**路线**：构造整系数线性型 `F_n = α_n + β_n π`，使 `|F_n|` 指数小、`β_n` 与（清分母后的）系数可控；
然后用"若 p/q 不是该型的根，则 `qα_n + pβ_n` 是非零整数"这一初等事实得到下界。

这条路线就是 Hata / Salikhov 的实际路线；Rhin–Viola 的置换群优化是同一框架下对参数与算术的优化。
本节把框架写成可计算的"成本模型"，然后逐族代入真实数字。

## 2. [证明] 归约引理

### 2.1 主引理（指数公式）

**引理 1.** 设 `ℓ_n = a_n + b_n π`，`a_n, b_n ∈ ℚ`，`b_n ≠ 0`。令 `D_n` 为使
`α_n := D_n a_n`、`β_n := D_n b_n` 同时为整数的最小正整数，`F_n := D_n ℓ_n = α_n + β_n π`。
假设存在 `A > 1`、`B ≥ 1` 与 `c_1, c_2 > 0`，使对所有大 n

```
c_1 A^{-n} ≤ |F_n| ≤ c_2 A^{-n},        |β_n| ≤ B^n.        (2.1)
```

则对任意 ε>0 存在 `c(ε)>0`，使所有 p/q ≠ π 满足

```
|π − p/q| ≥ c(ε) · q^{−(1 + log B / log A + ε)}.           (2.2)
```

*证明.* 固定 p/q。对任意 n，令 `X_n := q α_n + p β_n ∈ ℤ`。则

```
β_n (π − p/q) = F_n − X_n / q ,
```

故若 `X_n ≠ 0`，由 `|X_n| ≥ 1`：

```
|β_n| · |π − p/q| ≥ 1/q − |F_n| ,   即   |π − p/q| ≥ (1 − q|F_n|)/(|β_n| q).   (2.3)
```

取 `n = n(q)` 为使 `q|F_n| ≤ 1/2` 成立的**最小** n（由 `|F_n| → 0`，大 q 时存在）。
由最小性与 (2.1)：

```
q |F_{n−1}| > 1/2  ⇒  q ≥ 1/(2 |F_{n−1}|) ≥ (2c_2)^{-1} A^{n−1},
q |F_n|    ≤ 1/2  ⇒  q ≤ 1/(2 |F_n|)      ≤ (2c_1)^{-1} A^{n}.
```

两式夹出 `A^n ≍ q`（相差常数倍），即 `n = log q / log A + O(1)`。代入 (2.3)：

```
|π − p/q| ≥ 1/(2 |β_n| q) ≥ c q^{-1} B^{-n} ≥ c' q^{-1} q^{-log B/log A}
          = c' q^{-(1 + log B/log A)} .
```

**例外情形 `X_n = 0`（即 `p/q = −α_n/β_n`）.** 由 (2.1)，

```
|π + α_n/β_n| = |F_n|/|β_n| ≤ c_2 A^{-n} → 0   (n → ∞),
```

故序列 `{−α_n/β_n}` 收敛到 π。于是**对每个固定的有理数 r ≠ π，只有有限多个 n 使 `r = −α_n/β_n`**
（否则 r 是极限 π，矛盾）。又 `n(q) → ∞`（因 `|F_n| → 0`，且该收敛对 q 一致），故对
`q ≥ Q_0` 有 `n(q) > max{n : −α_n/β_n = p/q}`，即例外不发生。
剩下有限多个 `q < Q_0`（每个 q 只有有限多个 p，因为 `|π − p/q| < 1` 限定了 p），
逐例取最小正值即可（π 无理 ⇒ 每例下界 > 0）。∎

> **要点**：(a) 指数只依赖**衰减常数 A** 与**系数增长常数 B**；
> (b) 例外有理数不需要"双族独立线性型"假设，只需"每个有理数只有有限多个例外 n" +
> "n(q) → ∞"——两者都在 (2.1) 下自动成立。这是本文对任务中"例外处理"的答复：**例外不构成实质障碍**。

> **注意 (2.1) 是实质限制，不是废话。** 若只假设 `|F_n| → 0` 与 `ϱ_n ≤ 1`（Dirichlet 对每个无理数
> 都给出这样的序列：取 `b ≤ N` 使 `‖bπ‖ ≤ 1/N`，则 `ϱ = b‖bπ‖ ≤ 1`），本节论证会"证明"
> 每个无理数 `μ ≤ 2`——显然错误（Liouville 数 `μ = ∞`）。原因正是 Dirichlet 序列**不满足几何性**：
> `b_n` 可以相对 `b_{n−1}` 任意跳跃，而证明中把 `B^n` 换成 q 的幂次必须用"`⌈log q/log A⌉ ≈ n`"，
> 这要求序列按**同一个 n** 几何增长。用连分数时，几何性等价于 `q_{k+1}/q_k`（部分商）受控
> ——这就是 (4.4) 的来源。

**推论 1.1（质量形式）.** 定义**质量** `ϱ_n := |F_n| · |β_n|`。则 (2.1) 下 `ϱ_n ≍ (B/A)^n`，且

```
μ(π) ≤ 2 + log ϱ_n^{1/n} / log A   （沿子列取上极限），
```

因为 `1 + log B/log A = 1 + (log A + log ϱ_n^{1/n})/log A = 2 + log ϱ_n^{1/n}/log A`。

于是

```
ϱ_n 有界（≤ 1+o(1)）  ⟹  μ(π) ≤ 2 ；  反之 μ(π) ≤ 2 的任何成功族必满足 ϱ_n ≤ A^{o(n)} .   (2.4)
```

这就是全部问题的"成本语言"：**衰减 A 越大越好，质量 ϱ 越小越好；到 2 要求 ϱ 的增长被 ε 吃掉。**

### 2.2 与"内在（有理系数）形式"的关系：分母平方定律

线性型的值 `F_n = D_n ℓ_n`，系数 `β_n = D_n b_n`。故

```
ϱ_n = |F_n| |β_n| = D_n² · ( |ℓ_n| · |b_n| ) .                (2.5)
```

（这就是摘要里的恒等式；它是纯代数的，[证明]。）

**推论 2.1（该族的判据）.** 记内在质量 `q_n := |ℓ_n||b_n|`。则对几何族 (2.1)，

```
该族给出指数 ≤ 2   ⟺   D_n ≤ D*_n := q_n^{-1/2} · (1+o(1))  。          (2.6)
```

**含义**：任何线性型路线要成功，必须同时做到
(i) 内在逼近质量 `q_n` 足够好（不仅是 Dirichlet 最优，最好超 Dirichlet），
(ii) 清分母因子 `D_n` 不超过 `q_n^{-1/2}`。
**"分母条件"是唯一真正的瓶颈**——见 §6 的差距表。

### 2.3 [证明] 下界路线的循环性（为什么"对 |L_n| 给下界"不是出路）

任务要求"对 |L_n| 给出下界"。这条路线的地位可以精确说清：

**引理 2.** 若对某常数 `κ > 0` 与所有整数 a,b（`b ≠ 0`）有 `|a + bπ| ≥ c |b|^{-κ}`，则
`μ(π) ≤ 1 + 1/κ`。

*证明.* 设 `|π − p/q| = δ`。则 `|qπ − p| = qδ`；由假设（取 `a = −p, b = q`）
`qδ = |qπ − p| ≥ c q^{−κ}`，即 `δ ≥ c q^{−1−κ}`。∎

于是：
- `κ = 1` 给出 `μ ≤ 2`，而 `κ = 1` 的假设 `|a+bπ| ≥ c/|b|` **恰好就是 `μ(π) ≤ 2`**（两边等价）。
- 任何 `κ < 1` 的下界只给 `μ ≤ 1+1/κ > 2`。
- 而对**具体族**证明 `|F_n| ≥ c/|β_n|` 是同样的困难（它是族上的 Dirichlet 最优性）。

**结论：用"对 |L_n| 给下界"来回避例外，是把问题原样搬回来；κ=1 与目标命题等价（[证明]）。**
本文因此采用 §2.1 的"有限例外"处理，而不依赖任何 |L_n| 的定量下界。

## 3. [证明] 正权单积分族：为什么 `4 < e²` 是死因

### 3.1 构造（全部整系数、无需求解线性方程组）

取 `W ∈ ℤ[x]`，`W ≥ 0` 于 `[0,1]`，`deg W = N`。核心恒等式（初等）：

```
W(x) = Q(x)(1+x²) + (u x + v),   Q ∈ ℤ[x], u,v ∈ ℤ      （1+x² 首一 ⇒ 带余除法不产生分母）
∫₀¹ W/(1+x²) dx = A + (u/2)log 2 + v·(π/4),   A = ∫₀¹ Q ∈ ℚ .   (3.1)
```

若再要求 `W(i) = W(−i)`（例如 `W` 为偶函数，或 `n ≡ 0 (mod 4)` 时的 `W=(x(1−x))^n`），则 `u = 0`，
对数项消失，得到**纯 1 与 π 的线性型**：

```
L_n := ∫₀¹ W_n/(1+x²) dx = A_n + (v_n/4) π ,   v_n = W_n(i) ∈ ℤ .
```

清分母：`D_n := den(4 A_n)`，`α_n := 4 D_n A_n ∈ ℤ`，`β_n := D_n v_n ∈ ℤ`，则

```
α_n + β_n π = 4 D_n L_n .                                     (3.2)
```

对 `W_n = (x(1−x))^n`（`n ≡ 0 mod 4`）：`v_n = (1+i)^n = (−4)^{n/4}`，
`D_n | 4·lcm(1,2,…,2n−1)`。

### 3.2 严格下界（正性 ⇒ 无抵消）

因 `W_n ≥ 0` 且 `1/(1+x²) ≥ 1/2` 于 `[0,1]`：

```
L_n ≥ (1/2)∫₀¹ W_n dx = (1/2) B(n+1,n+1) = (1/2)·n!²/(2n+1)! .   (3.3)
```

结合 (3.2)：

```
|α_n + β_n π| ≥ 2 D_n · n!²/(2n+1)! .                          (3.4)
```

**这是无条件的**：不需要 |L_n| 的下界引理（那会循环），只需要被积函数非负。

**增长判定（精确阈值）.** 由于 `L_n ∈ [½B(n+1,n+1), B(n+1,n+1)]`（(3.3) 及 `1/(1+x²) ≤ 1`），
该族的整数线性型满足**双侧界**

```
2 D_n B(n+1,n+1) ≤ |α_n + β_n π| ≤ 4 D_n B(n+1,n+1) ,   |β_n| = D_n·4^{n/4} .    (3.5)
```

把 (3.5) 代入 §2.1 的指数公式，得该族的**精确判据**：

```
指数 ≤ 2   ⟺   D_n ≤ 4^{3n/8} = 1.68^n      （⟺ log D_n ≤ 0.226 n） .          (3.6)
```

*推导*：指数 `= 1 + [log D_n + (n/4)log 4] / [n log 4 − log D_n − O(1)] ≤ 2`
`⟺ log D_n + (n/4)log4 ≤ n log4 − log D_n ⟺ 2 log D_n ≤ (3/4)n log 4`。

**实测**（§3.3 的精确 `D_n`）`log₁₀ D_n ≈ 0.79 n = 6.2^n`，**比阈值大 `3.66^n`**，故
`|α_n+β_nπ|` 按 `≈(6.2/4)^n = 1.54^n` **增长**，给不出任何界。

**机制（[分析]）**：`D_n | lcm(1..2n−1)` 而 `lcm(1..m) = e^{m(1+o(1))}`，即分母税的量级是
`e^{2n}`；而一维正权积分的衰减上限是 `4^{-n}`（因 `|L| ≥ ½∫W`，且 `deg W = N` 时
整数多项式在 `[0,1]` 上的 L¹ 质量由整数 Chebyshev 常数 `1/4` 控制，见 §6.3）。
`4 < e²` 意味着**"税"必然吃掉"衰减"**。（(3.6) 的阈值形式把这一点说得更精确：
要成功必须把分母压到 `1.68^n` 以下——这已在 3.66 倍之外。）

`scripts/family_pos.py` 精确构造 `Q_n, A_n, v_n, D_n, α_n, β_n`，并用高精度 π 复核

|---|---|---|---|---|---|
| 4 | 8 | −4 | 7 | −1.4509 | −1.6532 |

| 12 | 24 | −64 | 8580495 | −0.3920 | −0.5954 |
| 16 | 32 | 256 | 29494189725 | 0.6769 | 0.4733 |
| 20 | 40 | −1024 | 33393321606645 | 1.2762 | 1.0725 |
| 24 | 48 | 4096 | 131762096268962445 | 2.4259 | 2.2221 |
| 32 | 64 | 65536 | 6157640021368865976621675 | 5.2183 | 5.0145 |
| 40 | 80 | 1048576 | 216850257105757801880233554675 | 4.9012 | 4.6973 |

实测平均增长率 `≈ +0.2…0.27 (log₁₀ per n)`，与 (3.5) 的 `log₁₀(e²/4) = 0.2665` 一致
（lcm 的跳跃导致抖动）。**严格下界与真实值只差一个常数因子（≈2），说明机制完全清楚。**

## 4. [计算] arctan 的 Padé 族：超 Dirichlet 质量 + 分母灾难

### 4.1 精确构造

`arctan x = Σ_{k≥0} (−1)^k x^{2k+1}/(2k+1)`。取
`Q(x) = Σ_{j≤n} q_j x^{2j}`（`q_0=1`）、`P(x) = x Σ_{m≤n} p_m x^{2m}`，令

```
Q(x) arctan x − P(x) = O(x^{4n+3}) .
```

等价于 n 个方程的 Hankel 型线性组（`scripts/pade_arctan.py` 用 `Fraction` 精确求解）：

```
Σ_{j=0}^{n} q_j (−1)^{m−j}/(2(m−j)+1) = 0 ,   m = n+1,…,2n ;
p_m = Σ_j q_j (−1)^{m−j}/(2(m−j)+1) ,        m = 0,…,n .
```

在 `x=1`：

```
E_n := Q(1)·π/4 − P(1) ,    4 E_n = Q(1) π − 4 P(1) .          (4.1)
```

清分母后得到**精确整数恒等式**（`D = lcm(den Q(1), den P(1))`）：

```
α_n + β_n π = 4 D E_n ,   α_n = −4 D P(1),  β_n = D Q(1) .      (4.2)
```

**高精度验证**（`scripts/tables.py`，π 取 200 位）：n=1…8 的 `|4D E_n − (α_n+β_nπ)| < 10^{−183}`。
例：n=1，`D=15`，`α=−76`，`β=24`，`α+βπ = 4·15·(8π/5·... )` 数值 `−0.2206 (log₁₀)`；核对
`|−76 + 24π| = 0.2206` ✓。

### 4.2 数值率（n = 1…40，`scripts/pade_arctan.py`）

```
log₁₀|E_n|   = −1.3675 n − 0.61      ⇒ |E_n| ≍ 23.31^{−n}
log₁₀|Q(1)|  = +0.1635 n + 0.05      ⇒ |Q(1)| ≍ 1.457^{n}
log₁₀ D_n    = +1.98   n − 2.2       ⇒ D_n   ≍ 95^{n}  （次指数修正，见下）
log₁₀|α_n+β_nπ| = +0.61 n            ⇒ 清分母形式 ≍ 4.1^{n}（增长！）
```

（由 n=20…40 的最小二乘拟合；`log D_n` 的底从 n 小时的 99 缓慢漂到 94，属 lcm/阶乘混合的次指数修正，
不影响任何结论。）

**所以：`log₁₀ D_n / log₁₀(1/|E_n|) = 1.98/1.3675 = 1.44 > 1` ⇒ 分母税超过衰减 ⇒ 失败。**

### 4.3 衰减常数的精确分解：Legendre 增益

数值上 `23.31 = 4(3+2√2) = 4(1+√2)²`。为了解释它，取正性核

```
J_n := ∫₀¹ (t(1−t))^n/(1+t²) dt  ∈ [ ½B(n+1,n+1), B(n+1,n+1) ]  （因 1/2 ≤ 1/(1+t²) ≤ 1）
```

并计算比值 `E_n/J_n`（`scripts/remainder_kernel.py`，高精度）：

| n | log₁₀\|E_n/J_n\| | 逐 n 斜率 |
|---|---|---|
| 4 | −3.1861 | −0.7122 |
| 8 | −6.1121 | −0.7387 |
| 12 | −9.0912 | −0.7476 |
| 16 | −12.0935 | −0.7520 |
| 20 | −15.1088 | −0.7547 |
| 24 | −18.1324 | −0.7565 |

斜率单调收敛到 **`−0.765551 = −log₁₀(3+2√2)`**（精确到小数点后 4 位）。
即

```
E_n = − c_n (3+2√2)^{−n} J_n ,   c_n ≈ 0.13·√n   (c₁₀=1.14, c₂₅=1.78, c₅₀=2.50) .     (4.3)
```

（`c_n ~ √n` 与 `J_n ≍ 0.886 n^{−1/2}4^{−n}` 相容；两者相乘给出 `|E_n| ≍ 0.245·23.31^{−n}`，
与 §4.2 的拟合截距 `10^{−0.61} = 0.245` 完全一致——这是本文对 (4.3) 的自洽性检验。）

**解读（这是"Legendre/超几何"内容）**：`J_n ≍ 4^{−n}` 是权函数的质量项，
`(3+2√2)^{−n} = (1+√2)^{−2n}` 是 **Legendre 增益**——来自正交多项式/求积余项在复奇点
`t = ±i` 处的增长（`|i + √(i²−1)| = 1+√2`，区间 `[−1,1]` 的 Bernstein 椭圆经过 `i`；因子 2n
来自余项核是 Legendre 多项式的**平方**）。两者相乘给出 `4(1+√2)² = 23.31`。

> 换言之：Padé/求积机制给出了"超 Dirichlet"的逼近质量——但这是**函数层面**的质量，
> 不是**有理数层面**的质量。见 4.4。

**推论（[计算]）**：`|E_n|·|Q(1)| ≍ 16^{−n}`。若 `Q(1), P(1)` 是整数（`D_n=1`），
由 (2.4) 立刻得到

```
μ(π) ≤ 1 + log(1.457)/log(23.31) = 1 + 0.1635/1.3675 = 1.12 ,
```

这当然不可能（Dirichlet 给 μ ≥ 2），**说明 `D_n` 必然很大**——这正是下面的定量事实。

### 4.4 分母灾难：Padé 值在 x=1 处是有理数，分母 ~95^n

`P(1), Q(1)` 是**有理数**；把它们约分后的分子/分母在 n=40 时已达 `10^{74}` 量级
（`scripts/pade_vs_cf.py`）。于是

- 内在质量 `|E_n||Q(1)| = 0.27·16^{-n}`（极好，超 Dirichlet 16 倍）；
- 质量 `ϱ_n = D_n² · 16^{-n} ≈ (95²/16)^n = 564^n`（灾难）。

**这正是 §2.2 的分母平方定律在起作用：需要 `D_n ≤ 4^n`，实际 `≈95^n`，差 `24^n`。**
结构原因：arctan 的 Padé 系数来自 Hankel 矩阵 `(1/(2(m−j)+1))` 的解，其分母是
`lcm(奇数)` 与阶乘型的混合，量级 `(2n+1)!!` 级别——**不是** lcm 型（`e^n`），而是 `~95^n`。

### 4.5 [计算] 连续分数收敛子：理想质量，但两种"陷阱"

**(a) Lambert 的 arctan 连分数不给好的 1,π 线性型。**
`arctan 1 = 1/(1 + 1²/(3 + 2²/(5 + 3²/(7+…))))` 的收敛子是整数 `p_k/q_k`。实测
（`scripts/pade_vs_cf.py`）对 `k ≤ 200`：

```
q_k·|π/4 − p_k/q_k| → 0.2654   （常数！）  ⇒  |q_k π − 4 p_k| → 1.0616 （常数！）
```

**即这些整数线性型 `q_kπ − 4p_k` 是 O(1)，不趋于 0**，完全无用。（因为 `4p_k` 不是 `q_kπ` 的
最近整数；arctan(1) 的收敛子不是 π 的收敛子。）

**(b) π 自身的连分数收敛子才是"理想质量"族。**
对 π 的部分商 `[3;7,15,1,292,1,1,1,2,…]`，收敛子满足
`|q_k π − p_k| < 1/q_{k+1}`，故

```
ϱ_k = q_k·|q_kπ − p_k| < q_k/q_{k+1} < 1    （Dirichlet 最优，自动满足！）
D_k = 1 （系数本来就是整数）
```

**这是唯一同时满足 C1、C2（见 §6）的族。** 实测（前 ~900 个部分商，`scripts/cf_pi.py`）：
`q_k|q_kπ−p_k| ∈ [0.003, 0.94]`，从不趋于 0 也不爆炸（典型的"Dirichlet 极值"行为）。
它的唯一障碍是**例外有理数** `p/q = p_k/q_k`。由 §2.1 的例外处理要用第 `k+1` 个形式，代价是
引入 `q_{k+1}/q_k`：

```
μ(π) ≤ 1 + limsup_k (log q_{k+1})/(log q_k) = 2 + limsup_k (log a_{k+1})/(log q_k) .   (4.4)
```

这是经典结论（[证明]：由 §2.1 的论证 + 例外情形）。**它是本文能给的最强"条件性"结果。**

实测（`scripts/cf_pi.py`）：`k ≥ 50` 时 `log a_{k+1}/log q_k ≤ 0.014`（条件指数 ≤ 2.014）；
全表最大 1.39（出现在 `k=1`，`a_2=15, q_1=7`，对应小 q，可单独粗估）。
`log q_600/600 = 1.1518`（Lévy 常数 `π²/(12 ln 2) = 1.1866` 的有限 n 偏差），
前 799 个部分商的 Khinchin 几何平均 2.655（理论 2.685），最大部分商 20776。
**数值上一切都像"随机数"（μ=2），但没有证明。**

## 5. [计算] 二维路线：Beukers 角点机制能赢，但只赢在 π² 上

### 5.1 角点机制确实能战胜 lcm 税

取（`scripts/beukers2d.py`）

```
I_n = ∫∫_{[0,1]²} (x(1−x)y(1−y))^n / (1−xy)^{n+1} dx dy
    = Σ_{k≥0} C(n+k,k) · B(k+n+1, n+1)² .                    (5.1)
```

（**曾在此处踩过一个索引错误**：权是 `x^n(1−x)^n`，所以 Beta 下标是 `k+n+1`，不是 `k+1`；
用 2D Gauss–Legendre 求积交叉验证后修正：n=1,2,3 时和式与求积相对误差 `1.4e−8, 8e−12, 1.3e−14`。）

数值（n ≤ 40，Richardson 外推）：

```
log I_n / n → −2.4056   ⇒  衰减底 = e^{2.4056} = 11.09 > e² = 7.389 .
```

**所以二维角点机制确实"赢过"lcm 分母税**（`D_n | lcm(1..n)²` 是 Beukers 的经典结果，
本文未重新证明；税底 `e²`），净衰减
`(11.09/7.39)^n = 1.5^n`。这就是 Beukers/Apéry 型构造能工作的定量原因，
也是 Rhin–Viola 优化的舞台。

### 5.2 [证明] 但它的值必属 `ℚ + ℚ·ζ(2)`

**引理 3.** `I_n ∈ ℚ + ℚ·ζ(2)`。

*证明.* (5.1) 的被加项是 `[k! n!/(k+2n+1)!]²·C(n+k,k)`，即 k 的**有理函数的完全平方**（乘一个
有理函数）。作为 k 的有理函数，其极点全部是**二阶**的（平方造成）。部分分式因此只有
`c/(k+j)²` 与 `c/(k+j)` 两类项；对 `k ≥ 0` 求和，前者给 `ζ(2)` 减有理数，后者给 digamma 的
有限部分（发散部分按 `Σc = 0` 抵消，留下有理数）。高次 ζ 值（`ζ(3), ζ(4),…`）**不可能出现**。∎

**推论**：这类积分的所有推广（Rhin–Viola 的置换群优化、Apéry 型加速）本质上给的是
**ζ(2) = π²/6 的无理性测度**，即 `μ(π²)`。

### 5.3 转换到 π 的因子 2 损失（精确障碍）

**引理 4.** 若 `μ(π²) ≤ ν`，则 `μ(π) ≤ 2ν`。

*证明.* 设 `|π − p/q| = δ`。则 `|π² − p²/q²| = δ|π + p/q| ≤ Cδ`，且 `p²/q²` 的分母 ≤ `q²`。
由 `μ(π²) ≤ ν`：`Cδ ≥ (q²)^{−ν}`，故 `δ ≥ C^{-1} q^{-2ν}`。∎

代入 Rhin–Viola 的 `ν = 5.441243`：

```
μ(π) ≤ 2 × 5.441243 = 10.88  >  7.6063（Salikhov 的直接界）
```

**所以二维路线即使做到 5.44，转回 π 也只有 10.88，严格劣于直接法。**
这就是"为什么 π 的纪录（7.6）走的是直接线性型而不是 ζ(2)"的定量解释，
也是本方向对二维路线的精确障碍陈述：
**需要的是"值为 ℚ+ℚπ（而不是 ℚ+ℚζ(2)）的角点型核"，而这样的核未知。**

（顺带：`x(1−x)y(1−y)` 权 + `1/(1+x²y²)` 型核给的是 Catalan 常数与二对数，
不是 `ℚ+ℚπ`；`1/(1+x²)` 的极点在 `±i`，距离区间为 1，**不落在角点上**，
所以对它取高次幂只产生 `2^{-m}` 的税，不产生指数增益。这正是 §3 死因的几何根源。）

## 6. [分析] 精确障碍：μ(π) ≤ 2 到底需要什么

把 §2–§5 整理成**可检验的必要条件**。设族为 `ℓ_n = a_n + b_nπ`（`a_n,b_n∈ℚ`），
`F_n = D_nℓ_n = α_n+β_nπ`（整数），`ϱ_n = |F_n||β_n|`，`q_n = |ℓ_n||b_n|`。

### 6.1 四条必要条件

- **C1（质量）**：`ϱ_n = D_n² q_n ≤ 1+o(1)`。由 (2.4)，这是 `μ(π) ≤ 2` 的**充要**条件。
- **C2（分母）**：等价地 `D_n ≤ q_n^{−1/2}`。**这是唯一实质瓶颈。**
- **C3（衰减）**：`|F_n| = D_n|ℓ_n| → 0`（否则引理 1 的前提不成立，得不到任何界）。
  在 C2 下 `|F_n| ≤ q_n^{-1/2}|ℓ_n| = |ℓ_n|^{1/2}/|b_n|^{1/2}`，故 C3 等价于 `|ℓ_n|/|b_n| → 0`
  ——即"逼近要比 Dirichlet 好"（这也正是 C1 的内容）。
- **C4（例外）**：不需要额外假设（§2.1 已证明"每个有理数只有有限多个例外 n"）。
  若硬要用"双族"，代价是 `q_{k+1}/q_k`——即部分商。

### 6.2 差距表（本文三条路线的实测常数）

记各量的"每 n 底"（`A` = 形式衰减底，`d` = 分母底，`b` = 系数底）：

| 族 | `A` | `d` | `b` | `q_n^{1/n}` | `D*_n^{1/n}` | `d/D*` | 判定 |
|---|---|---|---|---|---|---|---|
| arctan–Padé | 23.31 | 95 | 138 | 1/16 | 4 | 23.8 | ✗ 差 24^n |
| `(x(1−x))^n/(1+x²)` | 4 | 6.2 | 8.7 | ≈2^{−1.5} | 1.68 | 3.7 | ✗ 差 3.7^n |
| π 的连分数收敛子 | ≈1（`|F_k|`~1/q_{k+1}）| 1 | `q_k` | <1 | >1 | <1 | ✓ 通过 |

（`q_n^{1/n}` 一栏：Padé 为 `16^{-1}`，正权族为 `4^{-1}·4^{1/4} = 2^{-1.5}`，连分数为 `<1`。）

**结论**：
- **Padé 路线**的失败是**纯算术的**：逼近质量超 Dirichlet 16 倍（C1 的"质量"部分完全够），
  但分母超了 24 倍。要成功需要"求值点为整数（或分母 ≤ 4^n）的 arctan Padé 逼近"——
  这在文献中不存在，且本文的计算说明它不是"技术性"问题（分母来自 Hankel 系统的解，
  量级 `(2n+1)!!`）。
- **正权单积分路线**的失败是**结构性的**：衰减**不可能**超过 `4^{-n}`（[证明]，§3.2 的 (3.3)），
  而 lcm 税是 `e^{2n}`，且 `4 < e²`。定量地（(3.6)）：要成功必须 `D_n ≤ 1.68^n`，实测 `6.2^n`。
  **对"正权一维积分"类，衰减上限是硬的，所以问题被完全推给分母算术——而 3.66^n 的差距
  说明它不在"技术性优化"的射程内（[分析]）。**
- **连分数路线**是唯一通过 C1/C2 的，其障碍被压缩成 (4.4) 的**部分商**问题。

### 6.3 为什么一维不行、二维行：容量/鞍点的统一解释

**一维（正整数系数权）。** `|L| ≥ (1/2)∫₀¹ W`，而整数多项式在 `[0,1]` 上的
"整数 Chebyshev 常数"为 `1/4`（Fekete 的容量论证；`x^{N/2}(1−x)^{N/2}` 达到
`∫W ~ N^{−1/2}2^{−N}`，即**每个自由度衰减 2 倍**）。而 lcm 税是**每个自由度 `e` 倍**
（`lcm(1..N)^{1/N} → e`）。`2 < e`，所以"每自由度"的账总是亏：
```
一维： 衰减/度 ≤ log 2 = 0.693  <  税/度 ≈ 1  （log e）
```
（[分析] 级别：严格的部分是 `|L| ≥ ½∫W` 与 `lcm(1..N)^{1/N}→e`；
"整数多项式的 L¹ 质量每自由度最多衰减 2 倍"用的是容量 $1/4$ 与显式极值族 `x^{N/2}(1−x)^{N/2}`，
对**正**权是严格的，对有符号权则等价于 1,π,log2 的线性型下界，属更难的问题。）
**二维（Beukers 角点）。** 总度数 `4n`，衰减 `11.09^n`，税 `lcm(1..n)² = e^{2n}`：
```
二维： 衰减/度 = log(11.09)/4 = 0.602 ；税/度 = 2/4 = 0.5   ⇒ 0.602 > 0.5 ✓（勉强）
```
**判据（[分析]）：每自由度的衰减 log 值必须超过每自由度的 lcm 税。** 一维正权族的上限是
`log 2 = 0.693`，而税是 `log e = 1`，**每一维都在亏**；二维角点核才开始赚（0.602 > 0.5）。
这解释了为什么 Salikhov/Hata 必须在**高维**（多点 Padé / 重积分）里工作，
也解释了为什么"再优化一维族的参数"到不了 2。

### 6.4 到达 μ ≤ 2 需要什么（正面清单）

若要走通，需要**同时**满足：

1. **一个"整数友好"的 arctan 型 Padé 族**：`|E_n|·|Q(1)| ≤ 1`（或至少 `≤ A^{-εn}`），
   且 `den(P(1)/Q(1)) ≤ 4^n`。本文说明 Padé 的自然分母是 `~95^n`，差距 24^n；
   这需要"算术 Padé"（对 Hankel 解做整数化/加速），本文未找到。
   等价地：**需要 `ϱ_n ≤ 1`，即构造出 Dirichlet 质量的有理逼近**——而 Dirichlet 质量
   对每个 b 都存在（`|a+bπ| ≤ 1/(2|b|)`），但**固定结构**的族要达到它，就是猜想本身。
2. **或者**：控制 π 的部分商，使 (4.4) 的 `limsup log a_{k+1}/log q_k = 0`。
   数值上前 900 个部分商完全支持这一点（`k≥50` 时 ≤ 0.014），但这是关于 π 的
   **未证**陈述（等价于一类"π 不是 Liouville 型"的弱陈述）。
3. **或者**：找到值为 `ℚ+ℚπ` 的二维角点核（§5.3）。已知角点核给 `ζ(2)`；这是公开的空白。

## 7. [猜想] 与文献的关系

- **[猜想 7.1]** 任何"一维、正整数系数权、核为 `1/(1+x²)` 的幂"的构造，
  其清分母线性型都指数增长。§3.2 对正权给出**严格的衰减上限**（`|L| ≥ ½B(n+1,n+1)`，

- **[猜想 7.2]** arctan–Padé 的自然分母不可能被改进到 `4^n` 以下：Hankel 系统解的分母是

  若真能把分母压到 `4^n` 以下，由 (2.6) 立即得到 `μ(π) ≤ 1.13`，从而证明 `μ(π) ≤ 2`

- **[与文献一致]** Salikhov 的 7.6063 与本框架的 `1 + log B/log A` 相容：
  反解 `7.6063 = 2 + log ϱ/log A` 得 `log ϱ ≈ 5.6 log A`，即质量增长 `≈ A^{5.6}`，
  与"分母平方 × 大系数"的量级一致（[分析]，量级核对）。
