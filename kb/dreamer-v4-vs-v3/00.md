# 00 总览：DreamerV4 相对 DreamerV3 的改动（2026-11）

> **结论先行**：DreamerV4 不是 V3 的小版本升级，而是换了一套范式：从“在线交互 + 紧凑 RSSM + 从零 RL”换成“离线视频 + 可扩展生成式世界模型 + 先行为克隆再想象 RL”。世界模型、智能体训练、数据与算力四个层面同时变化，只有想象训练、λ-return、symexp twohot 等少数部件沿用。

**如果只记三件事**：

1. **世界模型换代**：V3 的 RSSM（GRU + 32×64 categorical latent + KL/重建）被 V4 的 causal tokenizer + block-causal transformer + shortcut forcing（流匹配/扩散式生成，每帧 4 步）取代。
2. **训练流程换代**：V3 在环境中在线采集，把 reward/continue 头与世界模型一起训，actor-critic 从零在想象里学；V4 先用 2.5K 小时 VPT 视频预训练世界模型，再训任务条件策略与 reward 模型（BC + MTP），最后用 PMPO 在想象里做 RL，全程不碰真实环境。
3. **代价换代**：V3 是 200M 参数、单张 A100、8.9 GPU 天；V4 是 2B 参数（0.4B tokenizer + 1.6B dynamics）、256–1024 张 TPU-v5p，换来单 H100 上 21 FPS 的实时交互世界模型，以及首个纯离线 Minecraft 钻石（0.7%）。

## 2. 一句话结论（六条）

1. **范式**：V3 是“在线交互、从零学世界模型和策略”；V4 是“离线视频预训练、把世界模型当模拟器、在模拟器里学策略”。
2. **世界模型**：V3 用 RSSM 把历史压成小状态；V4 用高容量 transformer 直接生成连续 latent 视频，靠 shortcut forcing 把每帧采样压到 4 步。
3. **智能体**：V3 的策略从零开始用 REINFORCE + return normalization + entropy 学；V4 先行为克隆，再用 PMPO 在想象里微调，PMPO 只看 advantage 符号，不需要 return normalization。
4. **数据**：V3 需要环境交互和奖励；V4 只需要固定数据集，reward 从数据集事件标注里学，且大部分视频可以没有动作标签。
5. **规模**：V4 把参数量从 200M 推到 2B，把训练从单卡 A100 推到 256–1024 张 TPU-v5p；这不是“同预算下的算法改进”。
6. **边界**：V4 只在 Minecraft、机器人、厨房视频上验证，没有重跑 V3 的 150+ 任务；论文是 v1 且无官方代码，结论应保留“未独立复现”的标签。

## 3. 改动地图（四层）

| 层面 | 一句话变化 | 详见 |
|-|-|-|
| 数据与任务 | 在线自采 → 离线 VPT 视频；单任务 → 20 任务 + task embedding；低分辨率 + 库存向量 → 高分辨率像素 + 低级键鼠 | 01、04 |
| 世界模型 | RSSM + KL/重建 → causal tokenizer + block-causal transformer + shortcut forcing | 02 |
| 智能体 | 单阶段在线 actor-critic → 三阶段：WM 预训练 → BC + reward → PMPO 想象 RL | 03 |
| 规模与代价 | 200M / 1×A100 / 8.9 GPU 天 → 2B / 256–1024 TPU-v5p / 未报告训练时长 | 04 |

## 4. 术语表

| 术语 | 含义 |
|-|-|
| Tokenizer | 把每帧图像压成一组连续 latent token 的因果编解码器；V4 中 400M 参数 |
| Dynamics | 在动作条件下预测下一帧 latent token 的 block-causal transformer；V4 中 1.6B 参数 |
| Shortcut forcing | 同时以“信号水平 τ”和“步长 d”为条件的流匹配/扩散目标；训练时可用少量采样步 |
| x-prediction | 网络直接预测干净数据 `x_1`，而不是速度 `v`；V4 用它减少长序列误差累积 |
| Agent tokens | 插入 dynamics transformer 的额外 token，读取任务嵌入并输出策略/奖励/价值 |
| MTP | Multi-token prediction，一次预测未来 L 步的动作或奖励；V4 用 L=8 |
| PMPO | 只看 advantage 符号、正负样本分开平均的策略目标；V4 用它替代 return normalization + entropy |
| VPT | OpenAI 的 Minecraft 视频预训练数据集/智能体；V4 用其 2.5K 小时 contractor 数据 |
| FVD | Fréchet Video Distance，衡量生成视频与真实视频分布的距离，越低越好 |
