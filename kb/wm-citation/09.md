- **新增论文**：在 `entries.py` 追加一条（id/zh/en/year/cites/venue/seeds/method/innov/motivation/contribution/approach/hardware/arxiv），在 `normalize.py` 的 `MAP` 里补方法/创新点标签，再重跑。

- **删除**：从 `entries.py` 删除并在 07 记录排除理由，保留可追溯性。

## 3. 数据字典（`data/entries.json`）

| 字段 | 含义 |
|-|-|
| `id` | 稳定标识（短名） |
| `zh` / `en` | 中文标题 / 英文原题 |
| `year` / `cites` / `venue` | OpenAlex 年份、引用数、发表场所 |
| `seeds` | OpenAlex 施引记录中命中的种子（D/D2/D3/J/JV/JV2/R/P） |
| `method` | 6 类方法类型之一（人工判读） |
| `innov` | 7 类创新点标签（可多选，人工判读） |
| `motivation` / `contribution` / `approach` / `hardware` | 中文概括（论文声称 + 人工提炼） |
| `arxiv` | arXiv ID（用于链接与全文抓取） |
| `appendix` | 是否属于 2023 年上半年附录 |
